# TypeTune 0.1.7 (13)

Предварительный релиз для macOS 14+ на Apple Silicon. Подпись ad-hoc, без нотаризации: при первом
запуске откройте приложение через контекстное меню «Открыть» или снимите карантин
(`xattr -dr com.apple.quarantine /Applications/TypeTune.app`). После обновления заново выдайте
TypeTune разрешения «Универсальный доступ» и «Мониторинг ввода».

## Новое

- **Короткие слова исправляются сразу.** Предлоги и местоимения из одной-двух букв (`d` → «в»,
  `yf` → «на», `z` → «я») исправляются на своём пробеле, как в Caramba, а если не решились сами —
  вместе со следующим словом (`yf ghbdtn` → «на привет»). Двухбуквенные аббревиатуры из заглавных
  (РФ, TV, CD) и токены со знаком (`T.`, `ab/`) не меняются.
- **Во всех полях, кроме паролей.** Первое слово после клика или перехода в приложение исправляется
  и в полях, которые не отдают текст через Универсальный доступ (например, строка поиска Google).
  Стираются только набранные символы. Поле с текстом, но без каретки сверяется по своему тексту.
- **Кто включил защищённый ввод.** Пока защищённый ввод включён, macOS не даёт TypeTune работать;
  теперь в настройках и подсказке флага видно, какое приложение его включило.
- **Диагностика.** Отчёт показывает признаки слов, которые словарь не стал исправлять (без текста).

## Как проверено

- CI на теге: Linux и macOS, selftest, XCTest, корпуса, пробник контроллера; архив собран
  `scripts/package.sh` из чистого тега, приложение из архива запускается без каталога сборки.
- Замер на естественном тексте (~0,8 млн слов): полнота коротких слов RU 0 → 93,1%, EN 0 → 95,3%;
  слов от трёх букв без изменений.
- Пользователь проверил сборку `99c015a` на своём Mac: «нормально работает» (ручная проверка, без
  отдельного набора сценариев). Релизный архив отдельно не проверялся вводом.

## Ограничения

- Одиночные заглавные английские буквы в английском тексте (`C`, `Z`, `D`, `B`, `R`) могут
  превращаться в русские («С», «Я», «В», «И», «К») — около 3–4 случаев на 100 тыс. слов по замеру.
  ⌘⌥Z возвращает и запоминает.
- В поле, которое не читается, кусок, дописанный к чужому слову и оказавшийся словом в другой
  раскладке, будет переписан; ⌘⌥Z возвращает.
- Не исправляются слова, которых нет в словаре: имена, названия, редкие формы. Может помочь
  настройка «Расширять словарь средствами macOS».
- Не проверены: Slack, VS Code, Word, Terminal, ввод пароля целиком, четырёхчасовой прогон.

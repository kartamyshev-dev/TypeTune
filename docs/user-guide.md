# Руководство пользователя

## Быстрый старт

1. Убедитесь, что приложение запущено (macOS — флаг `EN`/`RU` в строке меню; Linux — tray).
2. Печатайте как обычно.
3. Если слово «перекосило» раскладкой — дважды быстро нажмите **один и тот же Shift** (Double Shift).

## Double Shift (ручная коррекция)

- Два коротких нажатия **левого** или **правого** Shift без других клавиш между ними.
- TypeTune переписывает **последнее слово** у каретки по таблице клавиш US ↔ Русская (ПК) и переключает язык дальнейшего ввода.
- Повторный Double Shift на том же слове перекладывает обратно.
- Shift, удержанный для заглавной буквы, **не** считается жестом.

Примеры: `ghbdtn` → `привет`, `руддщ` → `hello`.

## Автокоррекция на пробеле

После пробела TypeTune может исправить слово сам, если:

- перекладка даёт правдоподобное слово целевого языка (частотный словарь),
- токен не похож на URL, e-mail, путь, идентификатор кода,
- слово не слишком короткое и не в смешанном регистре «как в коде»,
- приложение не в списке исключений.

Первое слово после смены раскладки (вашей или системной) **не** правится автоматически — чтобы не воевать с намеренным выбором языка.

## Меню (macOS)

| Пункт | Что делает |
|---|---|
| Флаг 🇺🇸 / 🇷🇺 / `?` | Текущая раскладка (или неизвестно) |
| Автопереключение | Авто-правка на пробеле |
| Ручное переключение | Double Shift |
| Переключать только последнее слово | Ограничить правку одним словом |
| Не переключать слова | Только смена раскладки, без правки текста |
| Не исправлять после смены раскладки | После Caps/смены языка пропускается **одно** авто-слово (анти-петля) |
| Звук переключения | Короткий сигнал при смене языка |
| Показывать флаг раскладки | Флаг в строке меню |
| Выученные слова… | Список и очистка |
| Отключить автопереключение в… | Исключения приложений |
| Активные раскладки… | Какие источники ввода считать EN/RU |
| Разрешения / Автозапуск / Открыть настройки | Системные пункты |
| Все выключено | Пауза |
| Выйти | Завершить |

## Слова и исключения

- **Выученные слова** пополняются после успешных правок; их видно в настройках и можно очистить.
- **Исключения слов** — не предлагать и не применять авто-правку к этим формам.
- **Исключения приложений** — выключить **авто**-правку в программе; Double Shift остаётся.

## Сниппеты

- Триггер начинается с `:`, завершается **пробелом** (например `:date` + Space).
- Сниппет имеет приоритет над автокоррекцией на том же диапазоне.

## Пауза

Перед паролями, кодами и другим чувствительным вводом включайте **Пауза** / **Все выключено**. История очищается; новые правки не выполняются.

## Чего не ожидать

- Гарантии в **каждом** приложении (кастомные редакторы, игры, некоторые терминалы).
- Полной поддержки IME и dead keys.
- Работы в системных полях паролей (secure input).

Диагностика: [troubleshooting](troubleshooting.md).

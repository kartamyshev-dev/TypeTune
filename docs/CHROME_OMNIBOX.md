## Поведение

В английской раскладке `ghbdtn` + пробел → `привет `.
Double Shift преобразует слово перед кареткой или выделение, как в полях страниц.
Автоматическая замена происходит после пробела; Enter не перехватывается.
Правильное `hello` сохраняется; `hello ghbdtn` + пробел → `hello привет `.

Вся строка должна состоять только из букв и обычных пробелов. Точка, слеш,
схема, email, цифра, двоеточие, знак вопроса, дефис и другие символы запрещают
любую замену во всей адресной строке — и автоматическую, и ручную.
`localhost`, `local`, `intranet` также сохраняются. Даже выделение обычного слова
внутри строки с URL не разрешает преобразование. Это консервативная политика:
например, `site:example.com ghbdtn` и запросы с цифрами тоже не исправляются.
Одно слово без признаков адреса рассматривается как поиск; отличить такой запрос
от нестандартного однословного имени intranet-хоста без информации о сети нельзя.

Ранний режим до пробела для адресной строки запрещён независимо от общего флага.
⌘⇧V здесь остаётся штатной вставкой Chrome. Пароли и другие поля панели инструментов
не разрешены. Сохраняются проверки Secure Input, AX, post-access, точного поля/окна,
выделения и UTF-16 до записи. URL-защита проверяется до изменения выделения и для
ожидаемого результата — пользовательское правило не может вставить адрес вместо слова.

Адресная строка определяется по AXTextField внутри AXToolbar до границы AXWebArea
и проверенному русскому/английскому AXDescription. Другие локализации Chrome пока
не добавлены. Поле страницы с похожей подписью не получает права адресной строки.

не открывались. CUA использовал clipboard только для первоначального локального

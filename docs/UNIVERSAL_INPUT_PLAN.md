# План: универсальная замена во всех приложениях

Решения пользователя от 2026-10-17:

- TypeTune должен исправлять раскладку во всех приложениях, а не только в TextEdit,
  Chrome и Codex.
- Механизм один для всех приложений, включая уже проверенные: свой буфер
  набранного слова, затем Backspace и повторный набор, как в оригинале
  (`docs/RESEARCH.md`, разделы «Буфер и повторная коррекция» и «Выдача исправления»).
- Если текст поля читается через AX, то перед удалением проверяется, что перед
  кареткой стоит именно набранное слово. Если не читается, исправление идёт
  по собственному буферу, без проверки.
- Выделение в приложениях, где AX его не отдаёт, преобразуется через буфер обмена:
  копирование, преобразование, набор, затем возврат прежнего содержимого буфера.

Следствия решений:

- Прежние native-PASS для TextEdit, Chrome и Codex к новому механизму не переносятся.
- Интеграция с zsh для Terminal и Ghostty отключается: терминалы обслуживаются
  тем же универсальным способом. Код интеграции удаляется отдельным шагом
  после native-проверки.
- ⌘⇧V (вставка без форматирования) не относится к исправлению раскладки
  и остаётся в прежнем ограниченном виде.

## Риски и защита

| Риск | Защита |
| --- | --- |
| Приложение само изменило текст (автозамена macOS, подсказка IDE, inline-автодополнение адресной строки), и Backspace сотрёт не то | Проверка через AX, где поле читается; буфер сбрасывается при любом событии, которое он не может учесть |
| Буфер разошёлся с полем: клик мышью, стрелки, Home/End, Tab/Enter, ⌘/⌃/⌥-сочетания, смена окна или раскладки другим способом, метод ввода, вставка | Сброс буфера; исправление только слова, целиком набранного подряд с клавиатуры |
| Пользователь печатает во время замены | Существующий барьер `MutationSession`: новый ввод задерживается и воспроизводится по порядку |
| Пароли | Secure Input и `AXSecureTextField` полностью отключают обработку, как сейчас |
| Терминальные программы (vim в обычном режиме, ssh) | Esc сбрасывает буфер; исключения программ в настройках по-прежнему действуют |
| Буфер обмена при работе с выделением | Прежнее содержимое (все типы) возвращается; если буфер обмена изменился во время операции, ничего не набирается |

## Этапы

Ядро (U0–U2) проверяется на Linux; GUI (U3–U7) — сборкой в CI на macOS и вручную на Mac.

- [x] **U0. `TypedWordBuffer` (Core)** — [evidence](../research/evidence/universal-u0-2026-10-17/verification.json). Текст, набранный подряд после последнего сброса:
  вставка, Backspace, сброс с причиной. Текущий токен, последний завершённый токен
  с разделителем (для Double Shift и отмены), предел длины, признак доверия.
- [x] **U1. `KeystrokeEditPlan` (Core)** — [evidence](../research/evidence/universal-u1-2026-10-17/verification.json). По решению движка вычисляет:
  - число Backspace для токена и разделителя;
  - текст для повторного набора;
  - обратный план для ⌘⌥Z;
  - ожидаемый текст перед кареткой для проверки через AX.

  Токен должен целиком состоять из символов, набранных клавишами.
- [x] **U2. Цель ввода без AX (Core)** — `InputTarget`; `MutationSession` уже обобщена и не меняется — [evidence](../research/evidence/universal-u2-2026-10-17/verification.json). `MutationSession` работает с `InputTarget`:
  pid и окно, AX-снимок необязателен. Проверка цели при воспроизведении
  использует AX, если он доступен.
- [x] **U3. Наполнение буфера (GUI)** — сборка и 7 проверок через настоящий `handle()` в CI на macOS; native NOT_RUN — [evidence](../research/evidence/universal-u3-2026-10-17/verification.json). `handle()` ведёт буфер по нажатиям через
  `InputSources.insertionText` и сбрасывает его по правилам из таблицы рисков.
  На этом шаге буфер ещё не используется для замен.
- [x] **U4. Отправка правки (GUI)** — за настройкой «Исправлять во всех приложениях», по умолчанию выключено; сборка и пробник в CI, native NOT_RUN — [evidence](../research/evidence/universal-u4-2026-10-17/verification.json). Внутри барьера:
  1. проверка через AX, если поле читается;
  2. N × Backspace;
  3. смена раскладки;
  4. набор текста событиями Unicode;
  5. воспроизведение задержанного ввода.

  Результат — «подтверждён», если AX после правки совпал, иначе «отправлен».
- [ ] **U5. Переключение функций (GUI).** Автоисправление, Double Shift по последнему
  слову и ⌘⌥Z работают через буфер. Выделение: AX `selectedText`, а если он
  недоступен — буфер обмена. Раннее исправление (экспериментальное) работает
  тем же способом.
- [ ] **U6. Снятие ограничений (Core и GUI).** Белый список приложений заменяется
  универсальной политикой: исключения пользователя, Secure Input и собственное
  приложение. Интеграция с zsh отключается. Статусы в строке меню обновляются.
- [ ] **U7. Документация.** README («Где работает»), DECISIONS, STATUS; чек-лист для Mac.
- [ ] **U8. Проверка на Mac** (вручную или с отдельного разрешения на NativeProbe вне TextEdit):
  - приложения: TextEdit, Заметки, Safari, Chrome (страница и адресная строка),
    Telegram, Slack, VS Code, Word, Terminal (zsh и vim), Codex;
  - режимы: автозамена macOS вкл/выкл, быстрый набор, выделение, ⌘⌥Z.

Каждый этап — отдельный коммит с evidence. Для этапов GUI сборку проверяет CI
на macOS после push.

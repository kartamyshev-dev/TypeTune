# TypeTune 0.2.3

Фикс метки в трее: рядом с флагом больше не «застревает» ✕.

## Fixed (Linux)

- Трей рассылает `org.freedesktop.DBus.Properties.PropertiesChanged`: GNOME-хост обновляет `XAyatanaLabel` синхронно с иконкой — раньше метка замеряла на стартовом значении, и рядом с флагом висел «✕»
- Свойства `Title` / `IconName` / `IconPixmap` / `ToolTip` / `XAyatanaLabel` / `XAyatanaLabelGuide` всегда согласованы при пуске, паузе и смене раскладки

## Артефакты

- **Linux:** `typetune-preview_0.2.3_amd64.deb`
- **macOS:** без изменений

## Установка

См. [docs/install.md](../install.md). После обновления перезапустите TypeTune.

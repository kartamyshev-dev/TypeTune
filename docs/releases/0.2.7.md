# TypeTune 0.2.7 — предварительный выпуск

Исправления нестабильной коррекции и запуска на macOS. Приложение получает
физические клавиши на HID-уровне, переводит их через активную раскладку и
отправляет замену в поток событий сеанса. Коррекция больше не зависит от того,
предоставляет ли редактор свой текст через Accessibility.

## Изменения

- Перевод физических кодов клавиш через TIS/UCKeyTranslate работает и тогда,
  когда раннее событие клавиатуры ещё не содержит готового Unicode-текста.
- Enter, навигация, команды и смена приложения начинают новую историю ввода.
  Реальная потеря событий по-прежнему запрещает замену неполного слова.
- Завершение старого наблюдателя больше не очищает историю нового поколения.
  Сон, неактивная сессия и блокировка экрана имеют независимые причины паузы;
  после снятия последней причины наблюдатель создаётся заново.
- Сохранены ограниченная очередь следующего ввода, сроки исполнения, проверка
  приложения-получателя, собственные метки событий и системный Secure Input.
- Диагностика разделяет распознавание Double Shift, отказ словаря, разрешения и
  этапы замены. Она не записывает слова, текст редактора или буфер обмена.
- Linux и macOS используют совместимый bridge protocol 3; диагностические поля
  добавлены без изменения правил жеста и автоматической коррекции.

## Проверки и ограничения

Все 280 локальных проверок прошли: 30 engine, 46 bridge, 17 portable
parity/gesture/feedback, 23 packaging и 164 Swift в 15 наборах.
На установленной диагностической сборке пользователь сообщил об улучшении.
После исправления зарегистрированы 3 manual и 5 automatic отправок с
`submitted/ack=ok`, без `rejected` или `indeterminate` для этих восьми операций.
Это результаты локальной сборки, а не нативная приёмка архива GitHub Actions.

`submitted` подтверждает отправку событий, но не итоговый текст редактора.
macOS backend не читает текст/выделение поля через AX: программное изменение
текста или каретки без событий ввода может остаться незамеченным. Жест исправляет
наблюдавшийся ввод; произвольный текст до запуска или после разрыва истории
не восстанавливается. Такие отправки не добавляют постоянные выученные слова.
Системный Secure Input блокирует коррекцию; свойства нестандартных защищённых
полей через AX не проверяются. Для чувствительного ввода используйте паузу.

Полная матрица приложений и физические сценарии сна, пробуждения и блокировки
остаются непроверенными. Релиз сохраняет канал Preview и не обещает одинакового
поведения во всех редакторах. Подробности: [текущий checkpoint](../macos-input-stability.md).

## Артефакты и установка

- macOS Apple Silicon, macOS 27: `TypeTune-macos-arm64.zip`, `MACOS-SHA256SUMS`.
- Linux amd64, Ubuntu 26.04/GNOME 50: `typetune-preview_0.2.7_amd64.deb`, `SHA256SUMS`.

Оба пакета публикуются одним тегом после успешных CI-проверок обеих платформ.
Завершите TypeTune перед заменой приложения. Подпись macOS остаётся ad-hoc,
без notarization: после обновления может потребоваться удалить и снова добавить
установленное приложение в Input Monitoring и Accessibility. Настройки сохраняются.
Установка: [docs/install.md](../install.md).

# TypeTune 0.2.4

Трей: только флаг и быстрое обновление при смене раскладки.

## Fixed (Linux)

- В трее больше нет текстовой метки `RU`/`US`/`✕` — только изображение флага (пустой `XAyatanaLabel` очищает закэшированные метки у хостов)
- Иконка флага обновляется сразу после переключения раскладки (~0.3 с вместо задержки до 3 с): окно подписано на сигнал моста `Changed` вместо одного опроса раз в 3 с; опрос сохранён как страховка

## Артефакты

- **Linux:** `typetune-preview_0.2.4_amd64.deb`
- **macOS:** без изменений

## Установка

См. [docs/install.md](../install.md). После обновления перезапустите TypeTune.

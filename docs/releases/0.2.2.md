# TypeTune 0.2.2

Мгновенная замена слова: вместо «печати» по буквам.

## Fixed

- **Linux:** compat-транспорт больше не выдерживает паузу 8 мс между клавишами замены — вся последовательность (Backspace + слово) уходит в uinput одной пачкой, слово появляется сразу
- **macOS:** убран sleep 3 мс между парами down/up при вставке замены — слово появляется сразу
- Прерывание новым вводом / cancel во время замены по-прежнему работает (на следующей итерации цикла)

## Артефакты

- **Linux:** `typetune-preview_0.2.2_amd64.deb`
- **macOS:** `TypeTune-macos-arm64.zip`

## Установка

См. [docs/install.md](../install.md). После обновления перезапустите TypeTune.

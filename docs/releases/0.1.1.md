# TypeTune 0.1.1

Стабилизация macOS-ввода после 0.1.0. Поведение функций прежнее; убраны причины «плавающих» Double Shift и авто-правки.

## Артефакты

- **Linux:** `typetune-preview_0.1.1_amd64.deb` (+ `SHA256SUMS`)
- **macOS:** `TypeTune-macos-arm64.zip` (+ `MACOS-SHA256SUMS`)

## Исправления (macOS)

- **Флаг раскладки** `EN` / `RU` / `?` в строке меню всегда отражает TIS (не зависит от списка «Активные раскладки»).
- **Caps Lock как переключатель раскладки** больше не сбрасывает историю слова и не блокирует Double Shift.
- **Авто на Space:** сравнение слова с AX игнорирует trailing-пробел (раньше правка «отклонялась» почти всегда, когда AX читал текст).
- **Модификаторы и клик мыши** не стирают текущее слово (раньше `flagsChanged` / pointer делали reset).
- **Мерцание AX** (поле на мгновение = nil) не сбрасывает историю и жест.
- **Event tap:** восстановление после disable не зависает; при отсутствии Input Monitoring в UI видно «Нужны разрешения…».
- **Быстрый Double Shift** (retoggle) не гасится искусственной задержкой.
- **Secure Input** (застрявший глобальный флаг password-менеджера) не отключает ввод в обычных полях; password-по-прежнему не трогаются.

## Диагностика

- `~/Library/Application Support/TypeTune/diag.log` — ход событий ввода и решений **без** набранного текста (для отладки на живой машине).

## Установка

См. [docs/install.md](../install.md). После **каждой** ad-hoc пересборки macOS может снять TCC-гранты — включите Мониторинг ввода и Универсальный доступ заново ([troubleshooting](../troubleshooting.md)).

## Ограничения

Как в 0.1.0: preview, не все приложения, Windows не входит, CI ≠ native acceptance.

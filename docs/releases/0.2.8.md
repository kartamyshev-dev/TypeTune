# TypeTune 0.2.8 — предварительный выпуск

Double Shift исправляет слова с цифрами: `ghbdtn123` → `привет123`.
Цифры больше не сбрасывают историю ввода и сохраняются при замене раскладки.
Выпуск дополняет HID/session backend из 0.2.7.

## Изменения

- Ручное преобразование RU ↔ EN сохраняет ASCII-цифры 0–9 в конце, начале
  и внутри слова, регистр букв и пробелы после слова.
- Повторный Double Shift возвращает исходное слово вместе с цифрами.
- Токен из одних цифр не вызывает замену текста или смену раскладки.
- Автокоррекция на пробеле по-прежнему пропускает весь токен с цифрами.
  Полная история не позволяет ошибочно исправить только суффикс после цифры.
- Протокол bridge 3 и правила распознавания жеста сохранены.

## Проверки и ограничения

Все 285 локальных проверок прошли: 31 engine, 48 bridge, 17 portable
parity/gesture/feedback, 23 packaging и 166 Swift в 15 наборах.
Проверены оба направления, регистр, цифры в разных местах слова, пробелы,
обратное преобразование, отказ для числовых токенов и следующая автокоррекция.
HID-fixture соединяет observer, Rust bridge и session output без AX и готового
Unicode в ранних клавиатурных событиях; события на рабочий стол не отправляются.
Форматирование, clippy engine/bridge без предупреждений и локальная сборка
с deep/strict codesign прошли.

На установленной диагностической сборке пользователь сообщил «вроде работает».
Разрешения listen/post/accessibility подтверждены после перезапуска,
зарегистрированы 8 отправок `submitted/ack=ok`. Точный текст и физический
сценарий с цифрами независимо не наблюдались. Это не нативная приёмка
релизного бинарника GitHub Actions.

`submitted` подтверждает отправку событий, а не результат в редакторе.
macOS исправляет непрерывно наблюдавшийся ввод без чтения текста или каретки
через Accessibility; программные изменения поля могут остаться незамеченными.
Постоянное обучение по таким отправкам не выполняется. Системный Secure Input
блокирует коррекцию, но произвольные защищённые поля отдельно не классифицируются.
Матрица приложений и физические sleep/wake/lock сценарии остаются непроверенными.
Канал выпуска — Preview. [Текущий checkpoint](../macos-input-stability.md).

## Артефакты и установка

- macOS Apple Silicon, macOS 27: `TypeTune-macos-arm64.zip`, `MACOS-SHA256SUMS`.
- Linux amd64, Ubuntu 26.04/GNOME 50: `typetune-preview_0.2.8_amd64.deb`, `SHA256SUMS`.

Оба пакета публикуются одним тегом после успешных CI-проверок обеих платформ.
Завершите TypeTune перед заменой приложения. Подпись macOS остаётся ad-hoc,
без notarization: после обновления может потребоваться удалить и снова добавить
установленное приложение в Input Monitoring и Accessibility. Настройки сохраняются.
Установка: [docs/install.md](../install.md).

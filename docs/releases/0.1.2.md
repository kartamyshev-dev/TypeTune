# TypeTune 0.1.2

Внешний вид строки меню: государственный флаг вместо текста EN/RU.

## Артефакты

- **Linux:** `typetune-preview_0.1.2_amd64.deb` (+ `SHA256SUMS`)
- **macOS:** `TypeTune-macos-arm64.zip` (+ `MACOS-SHA256SUMS`)

## Изменения

- В трее рисуется **флаг США / России** (21×14, отступы 10 pt) — не текст EN/RU.
- В шапке меню тот же флаг; неизвестная раскладка — `?`, пауза — `✕`.
- Небольшие правки документации (руководство, troubleshooting).

## Установка

См. [docs/install.md](../install.md). После ad-hoc пересборки macOS может снять TCC-гранты — см. [troubleshooting](../troubleshooting.md).

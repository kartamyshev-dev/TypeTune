# TypeTune 0.1.3

Стабильность ввода и паритет Status-меню с macOS.

## Артефакты

- **Linux:** `typetune-preview_0.1.3_amd64.deb` (+ `SHA256SUMS`)
- **macOS:** `TypeTune-macos-arm64.zip` (+ `MACOS-SHA256SUMS`) — без изменений кода приложения, пересборка для общего релиза

## Исправления (Linux)

- **Caps Lock / Fn** больше не стирают текущее слово и не блокируют Double Shift.
- **Модификаторы** (Ctrl/Alt/Super) сами по себе не сбрасывают историю; сочетания (Ctrl+буква) по-прежнему очищают.
- **Клик мыши / касание** не стирает слово — отменяется только незавершённый жест.
- **Смена раскладки** (Super+Space, Caps) сохраняет слово и пропускает **одно** авто-слово (анти-петля).
- **Мерцание фокуса GNOME** (окно на мгновение = 0) не сбрасывает историю.
- Bridge `infer` учитывает настроенную политику (`Переключать только последнее слово`, `Не переключать слова`, `Не исправлять после смены раскладки`).

## Изменения (Linux)

- В трее рисуется **флаг США / России** (21×14, отступы 10 pt) — не текст EN/RU; в шапке меню тот же флаг.
- Полное Status-меню как на macOS: авто/ручное переключение, политики правки, звук, флаг, выученные слова, исключения приложений, активные раскладки, разрешения, автозапуск, пауза, выход.
- Настройки schema v2 с generation ACK (трей и окно не теряют обновления).
- Опциональный звук переключения (`Звук переключения`, best-effort).
- Иконки флагов устанавливаются в `hicolor` внутри `.deb`.

## Ограничения

Как в 0.1.2: preview, не все приложения, парольные поля не распознаются в режиме совместимости (используйте паузу), Windows не входит.

## Установка

См. [docs/install.md](../install.md). После обновления выйдите из сеанса и войдите снова, если обновлялось расширение GNOME.

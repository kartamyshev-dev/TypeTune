# TypeTune 0.2.0

Нативная Linux-оболочка (GTK4/libadwaita + CLI doctor) рядом с Python runtime.

## Артефакты

- **Linux:** `typetune-preview_0.2.0_amd64.deb` (+ `SHA256SUMS`)
- **macOS:** без изменений кода приложения; артефакт пересобирается для общего релиза

## Добавлено (Linux)

- **`typetune-gui`** — нативное окно на GTK4/libadwaita: авто/ручное переключение, политики правки, звук, флаг, автозапуск, пауза, блок «Разрешения и состояние».
- **`typetune doctor --session`** — протокол, ОС, разрешения (`/dev/input`, `uinput`), раскладка (`input_source`), автозапуск; JSON со стабильными ключами (паритет с macOS `--doctor`).
- Бинарники `typetune-gui` и `typetune` упакованы в `.deb`; пункт «Нативные настройки (GTK)» в меню приложений.
- `TYPETUNE_NATIVE=1` переключает launcher на нативное окно; по умолчанию остаётся Python.

## Изменено (Linux)

- Политика моста (`switch_only_last_word` / `dont_switch_words` / `dont_correct_after_layout_change`) перечитывается при смене generation настроек, без правки словаря.
- `configure` передаёт `learned` явно (на Linux пока пусто; слова живут в `words.json`).

## Не изменилось

- Ввод по-прежнему обрабатывает Python `integrations/compat` (режим совместимости).
- Python SNI-трей остаётся штатным треем.
- Нет KDE/X11/Windows.

## Установка

См. [docs/install.md](../install.md). После обновления выйдите из сеанса и войдите снова, если обновлялось расширение GNOME.

## TypeTune 0.1.0-preview57-2 — Linux и macOS

Предварительный выпуск для двух платформ:

- **macOS 27, Apple Silicon:** скачайте `TypeTune-macos-arm64.zip` в разделе Assets.
- **Ubuntu 26.04 / GNOME Shell 50, amd64:** скачайте `typetune-preview_0.1.0.preview57-2_amd64.deb`.

Архивы **Source code** не содержат готового приложения. Работа во всех редакторах
не гарантируется; системные разрешения выдаются пользователем.

### Новое относительно preview57-1

- В macOS пункт меню меняется между «Пауза» и «Продолжить», а индикатор —
  между `TT` и `TT ⏸`.
- Подсказка индикатора показывает текущий статус; переключение из настроек
  также сразу обновляет меню.
- Добавлен regression test обновления элементов AppKit при паузе и продолжении.
- Linux: функциональных изменений относительно preview57-1 нет.

### Возможности macOS, добавленные в preview57-1

- Нативное macOS-приложение со строкой меню, русскими настройками и общим Rust-ядром.
- Double Shift, автокоррекция ABC ↔ «Русская — ПК», словари и предложения обучения.
- Исправлена потеря событий при конкуренции потоков и замена только окончания слова
  при неполной истории, когда редактор предоставляет текст через Accessibility.
- Автоматическая сборка обеих платформ и общая публикация только после успешного CI.

### Linux

### Изменения относительно preview52

- Удалён IBus-режим; оставлен единый compatibility runtime.
- Добавлены предложения автокоррекции после трёх ручных исправлений.
  Пробел можно нажать до или после Double Shift; обратный жест отменяет вклад случая.
- В меню приложений один ярлык TypeTune. Настройка доступна через его контекстное меню.
- Обновлены документация и план переноса Linux-поведения на Windows/macOS.

### Возможности

- Double Shift: исправить последнее слово и переключить язык ввода; повторный жест переключает обратно.
- Автокоррекция RU/EN после пробела, частотные словари и поддержка частых слов из двух/трёх букв.
- GTK-интерфейс, индикатор TT, настройки и автозапуск.
- Пользовательские слова, исключения слов и приложений.
- Предложения исключений после трёх отмен автозамены, только с явным подтверждением.
- Один режим коррекции; IBus-адаптер и переключатель режимов удалены.
- Предложения добавить слово в автокоррекцию после трёх ручных исправлений.
- Графическая первоначальная настройка; обновление и удаление с сохранением настроек.

### Скачать и установить

1. В **Assets** скачайте файл `typetune-preview_…_amd64.deb`.
2. Откройте его графическим установщиком пакетов.
3. В меню приложений откройте **TypeTune**: при необходимости настройка откроется автоматически. Повторная настройка доступна в контекстном меню ярлыка → «Настроить доступ и сеанс».
4. При первой установке или обновлении расширения GNOME, а также выдаче доступа к клавиатуре выйдите из сеанса и войдите снова.

`SHA256SUMS` содержит контрольную сумму пакета. Автоматические архивы **Source code** —
это исходники, а не готовое приложение. Пакет собран GitHub Actions из тега этого релиза.

### Проверки и ограничения

CI выполняет Rust/Python tests, контролируемые GTK-сценарии и изолированный
install/upgrade/remove/purge/reinstall через dpkg. Это не заменяет проверку реального
ввода в каждом приложении. На рабочей Ubuntu подтверждены установка предыдущей сборки
из .deb, миграция настроек и запуск package runtime.

Режим совместимости использует evdev/uinput без exclusive grab и не подтверждает
содержимое поля, выделение, пароль или composition. Доступ через группу input выдаётся
отдельно пользователем. Его членство в группе не отзывается при удалении пакета.
Счётчики предложений хранятся только до перезапуска runtime.

На тестовой машине snap-store 1390 блокировал установку .deb ошибкой AppArmor при
обращении к PackageKit. Если кнопка Install не работает, используйте другой системный
установщик либо APT; отключать AppArmor не требуется.


### macOS — Apple Silicon, macOS 27

Скачайте `TypeTune-macos-arm64.zip`, распакуйте и перенесите `TypeTune.app` в
`~/Applications`. `MACOS-SHA256SUMS` содержит контрольную сумму ZIP. Перед
обновлением завершите старую копию TypeTune; пользовательские настройки сохраняются.
Заменяйте существующую установленную копию, не оставляйте одновременно приложения
в `/Applications`, `~/Applications` и папке распаковки: macOS может показать каждую
копию отдельно в меню приложений.
В настройках приложения включите режим совместимости и выдайте системные разрешения
на мониторинг ввода и Универсальный доступ. Поддерживаются ABC и «Русская — ПК».

Это локальная preview-сборка с ad-hoc подписью, без Developer ID и notarization.
macOS может блокировать первый запуск загруженной сборки и потребовать повторной
выдачи разрешений после обновления. CI проверяет тесты и упаковку, но не подтверждает
работу физического ввода в каждом редакторе. Intel и другие версии macOS не заявлены.

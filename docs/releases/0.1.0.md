# TypeTune 0.1.0

Первый публичный выпуск.

## Артефакты

- **Linux:** `typetune_0.1.0_amd64.deb` (+ `SHA256SUMS`)
- **macOS:** `TypeTune-macos-arm64.zip` (+ `MACOS-SHA256SUMS`)

## Возможности

- Ручная коррекция раскладки RU ↔ EN (Double Shift) со сменой источника ввода
- Автокоррекция на пробеле по частотным словарям
- Выученные слова, исключения слов и приложений
- Сниппеты (Unicode)
- Меню: пауза, флаг раскладки, звук переключения (macOS)
- Preview-пакеты для Linux (GNOME / Wayland) и macOS (Apple Silicon)

## Установка

См. [docs/install.md](../install.md) (на русском).

## Ограничения preview

- Не гарантируется поведение во всех приложениях.
- macOS: ad-hoc подпись, без notarization; пересборка может потребовать повторной выдачи разрешений.
- Windows не входит в выпуск.
- CI не заменяет ручную приёмку клавиатуры (см. [docs/testing.md](../testing.md)).

# TypeTune 0.2.1

Hotfix: national flag in the GNOME tray.

## Fixed (Linux)

- Tray now shows **US / RU** via the shipped `typetune-flag-*.svg` theme icons instead of an `X`/tofu placeholder
- GNOME hosts that ignore `IconPixmap` still get the flag through `IconName`
- `xkb:us::eng`-style source ids map to the correct flag
- SNI label uses `US`/`RU` (emoji flags do not render on many Linux fonts)
- Package configure refreshes the hicolor icon cache

## Артефакты

- **Linux:** `typetune-preview_0.2.1_amd64.deb`
- **macOS:** без изменений

## Установка

См. [docs/install.md](../install.md). После обновления перезапустите TypeTune.

# 40 — Расширение словарей автокоррекции

Дата: 2026-09-16. Реализован первый срез этапа качества; весь этап не закрыт.
Основание: commit `18f366ed58ddb08799e527f0d4599a0bcf513f29` + текущие изменения.

## Изменение

Вместо ограничения 299 pilot словами подключены две pinned frequency lists
FrequencyWords 2018 (по 50 000 исходных записей). Происхождение, лицензия
CC BY-SA 4.0, исходники, checksum и воспроизведение — в
[атрибуции данных](../crates/typetune-engine/data/frequency/README.md).
Код TypeTune остаётся MIT; производные таблицы данных сохраняют CC BY-SA 4.0.
Installer копирует лицензию, атрибуцию и исходные списки вместе с библиотекой.

Build script проверяет структуру, количество строк, частотный порядок, дубликаты,
отбирает допустимые буквы и строит сортированные immutable таблицы.
В runtime используется двоичный поиск, без сети, файлового I/O и lazy загрузки.
Отсутствующие/повреждённые данные блокируют сборку, а не создают пустой словарь.
Runtime загрузка пользовательских словарей пока не реализована.

| Язык | Записи для защиты исходного слова | Допустимые цели замены, включая pilot |
|---|---:|---:|
| EN | 46 717 | 18 229 |
| RU | 48 249 | 18 592 |

Защита исходного текста использует весь отфильтрованный top-50k; цели — top-20k
и прежний pilot. Сохраняются длина 4–32, Space, guards, защита mixed case/code,
независимый ручной Double Shift и общий matcher для IBus/compatibility.
Rank — начальное ограничение частотности, не вероятностная уверенность.

## Проверки

До изменения matcher добавлен corpus test; старая версия падает на пропусках.
Корпус составлен до оценки нового matcher, разделён на dev/holdout; порог top-20k
не расширялся под оставшиеся пропуски. Это небольшой синтетический корпус,
не репрезентативная оценка повседневной печати.

| Выборка | Нужные замены | Старый matcher | Новый matcher | Отрицательные примеры | Ошибочные замены, старый / новый |
|---|---:|---:|---:|---:|---:|
| Dev | 26 | 12 | 23 | 26 | 0 / 0 |
| Holdout | 50 | 25 | 47 | 72 | 0 / 0 |
| Всего | 76 | 37 | 70 | 98 | 0 / 0 |

Охват на этом корпусе: 48,7% → 92,1%; точность выполненных замен: 100% в обеих
версиях на данной выборке. Оставшиеся шесть пропусков: «клавиатуры», «настройками»,
«исправления», «сохранение», «переключения», `keyboards`. Их неизменность закреплена
явно; редкие словоформы требуют следующего среза данных/правил.

AUTO-40: controlled range editor + fake clock проверяет текст, каретку, пробел,
сохранение префикса и совпадение с inferred profile по всем 174 cases.
Отдельно тот же корпус пройден через установленную release C ABI библиотеку.
116 Rust tests и 12 compatibility + 23 IBus/profile Python tests прошли;
SHA-256 исходных данных совпали. [Evidence](evidence/40-autocorrection.txt).
Среда: Ubuntu 26.04.1, Rust 1.98.1. Native Wayland/XWayland GUI acceptance
в этом срезе не запускалась; прежние результаты не выдаются за новую проверку.

## Пользовательская проверка и продолжение

Обновлённая библиотека установлена в пользовательский preview. Runtime на момент
обновления был остановлен и автоматически не включался. При уже загруженном bridge:

```sh
./scripts/typetune-test compat-on
```

В пустом поле с US введите `ljrevtyns` и пробел: ожидается `документы ` и RU
для дальнейшего ввода. Проверьте Double Shift обратно и ещё раз вперёд.

Остаются: более широкий независимый корпус, качество источников/морфология,
калибровка уверенности, короткие слова, пользовательские исключения и сохранение
настроек. Subtitle corpus содержит имена, сленг и ошибки; все слова и все приложения
не объявляются поддержанными. Существующие ограничения compatibility сохраняются.

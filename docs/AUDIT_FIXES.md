## Регрессии и воспроизведение

```sh
swift build --product layoutpilot-cli
.build/debug/layoutpilot-cli selftest
swift build --product LayoutPilot
sh scripts/statistics_store_probe.sh
sh scripts/single_instance_probe.sh
python3 scripts/test_audit_gates.py -v
python3 scripts/test_native_evidence.py
python3 scripts/test_native_integrity.py
python3 scripts/evaluate_corpus.py --report-prefix ../research/evidence/audit-fixes-2026-10-16-corpus
```

Все команды завершились с exit0. Авторский корпус: train3094/3094 и holdout1326/1326,
всего4420/4420; исходные корпус, native-v1 и словарь побайтно не изменились.
Прежние проверки identity/session17 и corpus integrity15 прошли. Новые Python
регрессии — два теста с отдельными положительными и отрицательными сценариями.
Компиляция выдаёт прежние предупреждения об отсутствующих каталогах CLT frameworks.
XCTest недоступен в CLT, его PASS не заявляется.

Новые тесты не читают пользовательский текст/clipboard, не посылают клавиши,
не меняют standard defaults и не запускают оригинал. Полные настройки при ошибке
не восстанавливаются автоматически: нужна сохранённая пользователем резервная
копия и перезапуск. Исторический raw native JSON без подтверждения процесса и
identity больше не проходит свежий валидатор; старые evidence не переписывались.

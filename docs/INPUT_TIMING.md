## Изменение

Для обычной вставки новый capture принимается после появления соответствующего
суффикса у курсора. Если его пока нет, AX-запрос откладывается на5мс и повторяется
в пределах мягкого бюджета60мс, пока ревизия и PID остаются прежними. Новое
событие/фокус отменяет прежний запрос. Один уже выполняющийся AX IPC может
превысить этот мягкий бюджет: жёсткий срок здесь не заявлен.

Суффикс — проверка готовности, не доказательство причинности: такая же буква
могла уже стоять у курсора. Перед заменой по-прежнему обязательны полное совпадение
ожидаемого текста/курсора и идентичность AX-цели, затем проверки до/после записи.
Несовпадения не превращаются в разрешение исправлять текущий текст вслепую.
Нормализация Unicode/границы графем и неподдержанные клавиши проверены отдельно.

## Физические модификаторы

Helper теперь явно нажимает и отпускает модификаторы вокруг сочетания/заглавной
буквы, с device-side битами из IOLLEvent.h. Раньше flags на обычном keyUp могли
оставаться установленными без соответствующего модификаторного кадра. Новый
finalModifierFlags фиксирует завершение, verifier отдельно сообщает, проверено
ли отсутствие активных Shift/Ctrl/Option/Command; старые JSON без поля не
получают это утверждение автоматически.

Прототип сохраняет контекст при доказанном отпускании Shift/Option/Command/Control.
Неизвестные клавиши и отсутствующие device-side биты при включённом aggregate
не считаются доказанным отпусканием. Новое нажатие/текст/мышь инвалидируют
транзакцию и отложенную смену источника как прежде. Добавлены27 offline-проверок.

## 2026-10-16: состояние жестов после replay release

На GUI ba8e8277 из1b79063 локализована отдельная причина двух gesture misses:
⌘⌥Space мог захватить Option release в mutation FIFO. Replay не вызывает
recognizer повторно, поэтому тот сохранял used Option press и отклонял
следующие Shift как перекрывающиеся. Контроль без diagnostic delay дал3/3;
существующий AX selection delay80ms воспроизвёл manual PASS и оба gesture FAIL
на том же бинарнике. В trace Optiondown → gate → replayed releases не сопровождается
обычным gesture Optionup; дальнейшие Shift не создают pending deadline.

[Разбор, границы утверждения и план native before/after](GESTURE_REPLAY_FIX.md).
Минимальный source patch отменяет старую модель жестов и Shift timer при
acquire barrier, replay и recovery. Пороги, TIS, FIFO и guards не меняются.
На момент patch проверки новой сборки ещё НЕ выполнены; старые native PASS/FAIL
остаются привязаны к своим GUI SHA. Этот дефект не объясняет автоматически все
исторические пропуски и не закрывает прочие timing/F07 ограничения.

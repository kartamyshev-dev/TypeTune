# Спецификация самостоятельного прототипа

Это контракт LayoutPilot, а не утверждение о полностью восстановленной спецификации
Caramba. Источники наблюдений оригинала: RESEARCH и FEATURES. Неизвестные правила
оригинала остаются открытыми. Ниже сценарии приёмки: наличие строки не означает PASS.
Статусы выполненных проверок и точные бинарные хеши находятся в STATUS/NATIVE/evidence.

Общее начальное состояние: только LayoutPilot, ABC + RussianWin, новый синтетический
документ TextEdit, разрешения выданы, системный словарь выключен. Авто/опечатки/ё
включены, пользовательские и обученные исключения пусты. Каждая проверка начинается
с явной установки раскладки и настроек. После проверки временные настройки удаляются.
Результат операции включает текст, диапазон UTF16, источник ввода и отсутствие
повреждения окружающего текста. Без надёжного AX-контекста допускается пропуск.

| ID | Условие и результат | Положительный сценарий | Отрицательный сценарий | Граничный сценарий |
|---|---|---|---|---|
| F01 | После разделителя известное слово другой раскладки преобразуется, источник меняется | ABC: ghbdtn + Space → привет + Space, RussianWin | ABC: hello + Space остаётся hello | ghbdtn123 остаётся; слишком быстрый контекст пропускается |
| F02 | Независимая настройка исправляет известную опечатку | RU: превет → привет | выключенная настройка сохраняет превет | неизвестное слово/неоднозначная опечатка сохраняются |
| F03 | Однозначная словоформа получает ё | RU: еще → ещё | настройка off сохраняет еще | неоднозначное все сохраняется |
| F04 | Одиночный короткий Shift после задержки переключает источник | ABC → RussianWin | Shift с буквой не считается одиночным | удержание ≥450мс не переключает; повтор у границы интервала |
| F05 | Double Shift/⌘⌥Space, при включении Option, конвертируют слово или выделение | ghbdtn123 → привет123; выделенное hello → руддщ с выделением | Option off ничего не меняет | пустое поле/новый фокус/emoji на границе не повреждаются |
| F06 | Оба разных Shift включают/выключают только паузу auto | пауза сохраняет ghbdtn; повтор возобновляет | один Shift не включает паузу | опечатки/ё продолжают работать при паузе auto |
| F07 | ⌘⇧V вставляет plain text в проверенное выделение | replace → synthetic clipboard | настройка off передаёт сочетание редактору | пустой/нестроковый clipboard, новое изменение clipboard не перезаписывается |
| F08 | После успешного исправления играет выбранный или стандартный звук | включить звук, выполнить исправление | off или пропущенная операция без звука | неподдерживаемый/удалённый файл сообщает ошибку либо использует стандартный звук |
| F09 | Исключённый bundle ID не обрабатывается | исключить TextEdit: ghbdtn сохраняется | удалить исключение: коррекция снова доступна | переключение между исключённым и обычным приложением сбрасывает контекст |
| F10 | Исключения слов приоритетнее пользовательской замены | lpfixture → проверка после Space | добавить исключение lpfixture: остаётся lpfixture | регистр ключа/пустой ключ/ключ с пробелом; правило только целого слова |
| F11 | Переключатель регистрирует/снимает SMAppService | on и статус enabled | off и статус disabled | denied/requiresApproval отображаются; реальный вход проверяется отдельно |
| F12 | Разрешения, Secure Input, конкурирующий switcher блокируют обработку | с AX работает | без AX/при Secure Input не изменяет поле | отзыв во время операции и возврат доступа, другой switcher |
| F13 | Только подтверждённая коррекция увеличивает счётчик | успешное исправление +1 | пропуск не меняет счётчик | сохранение после перезапуска; оценка 2сек — собственная формула |
| F14 | ⌘⌥Z отменяет последнюю подтверждённую операцию; auto-исходник обучается как исключение | привет → ghbdtn, возвращается исходный ABC | после внешнего изменения отмена пропускается | manual hello→руддщ→hello при исходной RussianWin; ⌘Z принадлежит редактору |
| F15 | Точный AX-target, Unicode и FIFO защищают текст | emoji/NFD перед исправляемым словом сохранены | иной PID/поле/документ не получает прежнюю замену | ввод во время AX-выделения сохраняет порядок; зависший ACK требует восстановления |
| F16 | Меню и настройки показывают фактический статус и сохраняют выбор | тема/настройка сохраняется после перезапуска | закрытие настроек не завершает приложение | выключение/выход при задержанном вводе требуют его разрешения |

## Что уже проверено и что предстоит

Штатная native-smoke13 покрывает положительные F01–F05, F07, F14 и часть F15.
Отдельные controls6 проверяют F05/06; app-exclusion и literal-rule/word-exclusion
проверяют F09/10. manualUndo фиксирует промежуточную замену: совпадение конечного
текста с начальным само по себе не доказывает отмену. Unicode и delay80-поток
проверяются отдельно. Регистрация F11 проверена через UI без выхода из macOS.

Полные отрицательные/граничные native-наборы, звук на слух, защищённые поля,
отзыв разрешений, сон/пробуждение, смена приложений и реальный вход пока не приняты.
Offline-инварианты дополняют эти проверки, но не заменяют их. Сценарии для других
приложений не запускать текущим NativeProbe: его авторизация ограничена новыми
тестовыми документами TextEdit.

## Уточнение собственного контракта F07/F09 (2026-10-15)

- F07 Chromium: после CmdShiftV сначала получаются отпускания V/Cmd/Shift и
  neutral flagsChanged; текущее глобальное состояние также должно быть neutral.
  Без отпусканий за2с, при новом вводе/фокусе/clipboard вставка отменяется.
  Используется команда редактора CmdAltShiftV, без временного изменения clipboard.
  LF/TAB остаются данными вставки. Структурный AX LF пустого rich-поля допускается
  только в readback equivalence при before='\n'/caret0; реальные LF не удаляются.
  На425e44e3 проверены оба Chrome-поля и отрицательный опыт удержания2.3с;
  полный набор F07/прочие hosts остаются открытыми.
- F09: `appAutomatic[bundleID]=false` запрещает auto layout и собственные literal
  rules в этом приложении; true не отменяет global automatic=false. Typo/ё/manual
  остаются независимы. Полная блокировка excludedApps имеет более высокий приоритет.
  Это отдельный собственный параметр; не следует смешивать два вида исключений.

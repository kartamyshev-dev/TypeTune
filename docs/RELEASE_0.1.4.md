# TypeTune 0.1.4 (10)

Предварительный релиз для macOS 14+ на Apple Silicon.

Исправлены удержание событий при быстром вводе, обработка очереди восстановления,
ручное преобразование Apple «Русская» и поток Chrome. Chrome теперь допускает
ограниченное повторное чтение, если AX сообщил новую каретку раньше нового текста;
точное подтверждение текста/каретки и защитные ограничения сохранены.
Включены изменения после v0.1.3: пунктуация в неверной раскладке, полная пауза,
расширенный независимый словарь и исправление двух заглавных букв.

До обновления метаданных версии кандидат bdecb08f прошёл Chrome48/48,
CLI1336/1336, corpus4420/4420, controller70/70, guard23/23. Native PASS
не переносится на переупакованный bundle; Apple/10 мс/⌘⌥R проверялись на более
ранних кандидатах. Подробности: [Chrome](MAC_CHROME_CARET_FIX_2026-10-18.md).

Четырёхчасовой прогон NOT_RUN по указанию пользователя. Полная приёмка PLAN
не завершена. Подпись ad-hoc, notarization отсутствует. При обновлении macOS
может потребовать обновить существующие разрешения приложения.

Релизная сборка: GUI SHA-256 `c722c3d7c553494a80f0d1e62986e2d38bedbc9fa7c3e8c2d91fd8eadc566ac7`.
На ней повторены CLI1336/1336, corpus4420/4420, guard23/23, controller70/70,
audit4/4 и fixtures8/8. Native на релизном bundle не запускался.

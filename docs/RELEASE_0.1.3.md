# TypeTune 0.1.3 (9) — предварительный релиз

Исправлены ожидание подтверждения замены через Универсальный доступ и
дублирующее чтение поля при отпускании клавиши. Подтверждённое восстановление
выделения до записи текста больше не оставляет ложную блокировку. Диагностика
сохраняет техническую причину отказа без пользовательского текста.

Выпущен ранее проверенный бинарник build9, без пересборки:
`920564da6286b592964bd51db8391d0290602ec695a56f4ad8475d4e61ff4713` (SHA-256 GUI).
Исходники сборки: `4099b12`; исходники в теге релиза совпадают по всем compiled inputs.
Последующие коммиты добавили evidence, документацию и упаковку.

Проверки этого бинарника:
- CLI: 720/720; корпус: 4420/4420 (offline).
- Контроллер: 62/62 (изолированная проверка, не XCTest).
- TextEdit: поток 80 мс — 12/12, все 192 слова, точные текст/каретка/раскладка.
- Автоотмена и обучение — 2/2; тестовое исключение удалено, настройки восстановлены.
- После удаления исключения: первое слово, быстрый Double Shift и поток — 3/3.

Требования: macOS 14+, Apple Silicon. Распакуйте архив, перенесите TypeTune.app
в «Программы». Перед заменой завершите старую копию и сохраните её для отката.
Разрешения «Универсальный доступ» и «Мониторинг ввода» управляются в системных
настройках. Подпись ad-hoc; notarization Apple отсутствует.

Это предварительный релиз: четырёхчасовой прогон и рабочий день наблюдения
ещё не выполнены. Полная стабильность и все приложения не приняты. Проверки
других сборок не перенесены на этот бинарник. Раннее исправление и вставка
без форматирования не входят в принятую область коротких проверок.

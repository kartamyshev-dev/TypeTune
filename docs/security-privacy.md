# Безопасность и конфиденциальность

## Данные

| Данные | Где живут | Что запрещено |
|---|---|---|
| История нажатий для коррекции | Только RAM, ограниченный буфер | Запись в логи, сеть, crash-отчёты |
| Выученные слова / исключения | Локальные файлы настроек пользователя | Автозагрузка, аналитика |
| Clipboard | Не используется для правок в штатном пути | Сохранение на диск |
| Содержимое полей (Accessibility) | Логика in-flight на время правки | Логирование, персистентность |

TypeTune **не** содержит телеметрии текста и не отправляет статистику ввода.

## Чувствительный ввод

- Системный **Secure Input** и известные password-поля: обработка пропускается, история не копится.
- Перед паролями, кодами и секретами включайте **Пауза** / **Все выключено** — это самый надёжный выключатель.
- Звук переключения и авто-правки молча выключаются на паузе и в чувствительных контекстах.

## Привилегии

| Платформа | Зачем | Границы |
|---|---|---|
| macOS | Input Monitoring (наблюдение), Accessibility (контекст/проверка текста) | Только для коррекции; без скриншотинга и снятия буфера |
| Linux | polkit + доступ к выбранным `/dev/input` | Устройства выбираются явно; helper не root-сервис «для текста» |

Отзыв разрешений останавливает коррекцию; статус в UI становится «нужны разрешения», а не ложным «работает».

## Целостность пакетов

- Релизы публикуются CI после успешных проверок обеих платформ.
- Рядом с артефактами — `SHA256SUMS` / `MACOS-SHA256SUMS`.
- macOS preview: ad-hoc подпись, **без** notarization — доверяйте только официальным Releases.

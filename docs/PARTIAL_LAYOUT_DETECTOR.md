# Самостоятельное раннее распознавание раскладки

`PartialLayoutDetector` — консервативная самостоятельная замена частичной модели
для F01. Префиксы вычисляются **только из текущего авторского Lexicon**. Код не
использует извлечённые словари, веса или pattern IDs Caramba. Оригинал проверяет
partial/complete model keys и перекрывающиеся byte-pattern IDs; префиксное
множество не воспроизводит этот классификатор и его качество не установлено.

## API и стоимость

```swift
let decision = Engine(settings: settings).decidePartial("ghb", context: context)
// .layout: ghb → при, targetLanguage .russian

// Для своего или изменённого Lexicon индекс строится один раз из snapshot:
let detector = PartialLayoutDetector(lexicon: customLexicon)
let customEngine = Engine(settings: settings, lexicon: customLexicon)
let custom = customEngine.decidePartial("ghb", context: context, detector: detector)
```

`PartialLayoutDetector.bundled` — однократно инициализируемый неизменяемый индекс.
Создание обычного `Engine` не строит префиксы. Каждая проверка делает bounded
обход токена и два set lookup; словарь на каждом нажатии не сканируется.
Пользовательские исключения/правила проверяются отдельно. `Lexicon` остаётся
изменяемым; существующий detector сам за его изменениями не следит. Вызывающий
код обязан пересоздать custom detector вне per-key пути при смене vocabulary.
Default detector всегда bundled, даже если Engine.lexicon изменён: во избежание
скрытого rebuild custom detector передаётся явно.

## Контракт

- Глобальная пауза, запрет автоматического режима для приложения, исключённое
  приложение, secure или unreliable context запрещают результат.
- Только 3…64 графемы, состоящие исключительно из ASCII EN или стандартных
  RU букв, включая ё. Смешанные алфавиты, цифры, пробелы, NFD/combining marks,
  URL, пути, code и любые знаки препинания отклоняются.
- Uppercase после первого символа запрещён; первый регистр сохраняется обычным
  физическим `Layout.convert`. Нет исправления регистра, typo, ё или rule.
- Полное исходное слово и любой его префикс, известный в своём языке, запрещают
  смену. Требуется известный префикс преобразованного токена в другом языке.
  Полные словарные слова также входят в prefix set.
- Excluded/learned entries защищены ещё до завершения: исходный или целевой
  токен, являющийся префиксом такой записи, не преобразуется. Источник literal
  user rule также защищён до завершения, чтобы частичная обработка не мешала
  будущему применению правила. Пустые записи ничего не блокируют.
- Результат имеет только reason `.layout`. Это предложение преобразовать токен
  и целевой язык, а не разрешение на AX mutation или изменение TIS.

Physical punctuation keys здесь намеренно не поддержаны: до разделителя
неизвестно, является ли `ghb,` началом filename/code или словом с клавишей «б».
Существующее whole-word преобразование таких клавиш от этого не меняется.
Отсутствие исходного префикса в небольшом авторском словаре не доказывает, что
введённое слово неверно: имена и неизвестные слова остаются источником ложных
срабатываний. Ранний перевод также может помешать ещё не введённому суффиксу
URL/path/code; проверка уже набранного токена не предсказывает будущий ввод.

В оригинале короткий UTF-8 count-helper считает Unicode scalars, а не графемы.
Для принятого здесь чистого RU/EN набора без combining marks количества
совпадают. Это не утверждение об эквивалентности остальных правил оригинала.

## Проверки и границы

`Sources/LayoutPilotCLI/PartialLayoutChecks.swift` экспортирует
`partialLayoutChecks()`. Независимые ожидания: ghb→при, ghbd→прив; правильные
слова и source prefixes; mixed/case/acronym/URL/path/code/digits/whitespace/NFD;
контексты, исключения и настройки; snapshot custom lexicon; отсутствие участия
его typo/ё таблиц. Словарь и контрольный корпус ради этих проверок не менялись.

На момент подготовки сборка/выполнение проверок отложены координатором.
Интеграции с клавиатурой в этой работе нет; native F01, качество классификации,
задержка и parity с оригиналом не заявляются.

## Предложение для текста и каретки

`Engine.partialProposal(in:selection:context:detector:) -> PartialLayoutProposal?`
возвращает `{range: NSRange, decision: Decision}`. Диапазон относится к UTF-16
исходного текста и включает только текущий токен. Полный текст ограничен 65536
единицами UTF-16; выделение запрещено. Каретка должна находиться на границе
графемы у конца токена: следующий символ — whitespace либо конец текста.
`wordBeforeCursor(skipTrailingSpace: false)` не перепрыгивает уже введённый
разделитель; на пробеле после слова предложение отсутствует. Позиция внутри
слова/filename, surrogate/NFD, отрицательный/вышедший за текст диапазон
отклоняются. Emoji и NFD вне токена сохраняются и не мешают корректному range.

Это только чистое предложение. Перед записью runtime обязан повторно проверить
полный текст, каретку, AX-цель, source/revision, Secure Input и разрешения.
Отдельные проверки range API подготовлены вместе с CLI checks; их выполнение
пока отложено координатором. Включение opt-in UI и native проверка — другая работа.

## Интеграция 16 октября

Runtime добавлен под отдельной настройкой «Раннее исправление раскладки
(экспериментально)», выключенной при отсутствии собственного ключа earlyCorrection.
Существующие настройки не мигрируют принудительно в этот режим. Полный свежий
AX target/text/caret должен совпасть с прогнозом и перед ранней записью;
предсказанный кэш сам по себе записи не разрешает. Новое ядро вошло в
558/558 исполненных CLI-инвариантов, авторский корпус4420/4420 не изменился.
Evidence: accelerated-cli-selftest.txt, accelerated-corpus.txt.
Это ещё не native-приёмка раннего режима. Сценарий suffix во время mutation
проверяется отдельно; старые строки «отложено» выше описывают подготовку API.

# Самостоятельное изображение шапки F19

Store предоставляет `headerImage`, `headerImagePath`, `chooseHeaderImage()` и
`resetHeaderImage()` для собственного интерфейса LayoutPilot. Ресурсы и код
оригинальной программы не используются.
`importHeaderImage(from: URL)` принимает только локальный fileURL из явного
действия пользователя; `importHeaderImage(data: Data)` принимает TIFF/другой
поддержанный raster payload из drop на шапку. Оба используют одинаковые
проверки и собственное хранилище. UI вызывает их на main. Глобального чтения
clipboard или фонового получения изображений нет.

Выбранный пользователем image-файл проверяется до копирования: регулярный файл,
не более32MiB, raster metadata с положительными размерами до8192 на сторону и
16 777 216 пикселей всего. Для отображения создаётся thumbnail до2048px средствами
ImageIO; исходные байты сохраняются без перекодирования под UUID в
`~/Library/Application Support/LayoutPilot/HeaderImages/`. Для многостраничных
и анимированных файлов отображается первый кадр. Векторные/неподдержанные ImageIO
форматы отклоняются с сообщением, а не заявляются поддержанными.

В UserDefaults записывается только путь собственной копии `headerImagePath`.
При запуске загрузка допускается только из этого собственного каталога,
проверенного после разрешения symlinks; чтение произвольного сохранённого пути
не разрешается. При пропавшей/невалидной копии изображение не загружается,
выбор сохраняется до явного сброса. Содержимое изображения не пишется в журнал.

Сброс убирает настройку и изображение из UI. Оригинал не изменяется и не
удаляется. Предыдущие собственные копии пока остаются в HeaderImages; полное
удаление данных приложения должно явно включать этот каталог.

Проверки адаптера: настоящий Store прошёл25/25 runtime-инвариантов с собственными
PNG/TIFF-данными, включая пределы, ошибки, restart/reset и неизменность исходника:
[HEADER_IMAGE_PROBE](HEADER_IMAGE_PROBE.md). На GUI803c1fab проверены выбор
синтетического PNG через системный диалог, отображение, quit/restart и сброс;
[UI evidence](../research/evidence/header-pilot-ui-verification.json).
Это отдельные проверки, не перенесённые на последующие бинарники. Сам drop
через SwiftUI ещё не проверен нативно; полная приёмка F19 остаётся открытой.

# Установка

## Linux (`.deb`)

### Требования

- Ubuntu 26.04 (или совместимая), GNOME Shell 50, сессия Wayland, amd64.
- Права пользователя для доступа к `/dev/input` (выдаётся помощником через polkit).

### Шаги

1. Скачайте `typetune_*.deb` из [Releases](https://github.com/kartamyshev-dev/TypeTune/releases).
2. Установите **через APT / dpkg**, не через GNOME Software для локального файла:

   ```sh
   sudo apt install ./typetune_*.deb
   ```

3. Откройте **TypeTune Setup** в меню приложений → **Настроить** (запрос пароля polkit).
4. **Выйдите из сеанса и войдите снова** — расширение GNOME и session helper загружаются при входе.
5. Запустите TypeTune, при необходимости включите режим совместимости в настройках.

### Обновление и удаление

- Настройки пользователя сохраняются при обновлении пакета.
- `sudo apt remove typetune-preview` (имя пакета — в `dpkg -l | grep typetune`) удаляет программу; пользовательские слова/исключения можно удалить вручную из каталога конфигурации, если они больше не нужны.

## macOS (`.zip`)

### Требования

- Apple Silicon, macOS 27.
- Разрешения: **Input Monitoring** и **Accessibility**.

### Шаги

1. Скачайте `TypeTune-macos-arm64.zip` из Releases.
2. Распакуйте и перенесите `TypeTune.app` в `~/Applications`.
3. Откройте приложение (ПКМ → Открыть, если Gatekeeper спросит — подтвердите запуск).
4. В настройках нажмите **Разрешения** и выдайте Input Monitoring и Accessibility.
5. Проверьте статус в строке меню: флаг `EN`/`RU` вместо «нужны разрешения».

### Подпись и обновления

- Сборка ad-hoc, **без** notarization. Это preview-канал.
- **Пересборка** приложения (другой cdhash) может «сломать» ранее выданные разрешения: удалите старую запись в «Настройки macOS → Конфиденциальность и безопасность» и добавьте текущую копию заново.
- Автообновления нет: скачивайте новый ZIP из Releases.

## После установки

1. Наберите в текстовом поле `ghbdtn`, поставьте пробел или дважды быстро Shift — ожидается `привет` и русская раскладка.
2. Если правки нет — см. [troubleshooting](troubleshooting.md) и [testing](testing.md).

# Проверка на Mac вручную (около 15 минут)

Актуальные правила работы агента на Mac — [MAC_AGENT_GUIDE](MAC_AGENT_GUIDE.md)
(DECISIONS п.31). Здесь описана самостоятельная проверка пользователя; её результаты
записываются как `user manual` с SHA конкретной сборки.

## 1. Установка тестовой сборки

1. Откройте запуск CI нужного коммита: GitHub → Actions → ветка (обычно `universal-input`).
   Внизу страницы, в разделе Artifacts, скачайте `TypeTune-test-<коммит>`.
   Другой способ — в терминале: `gh run download <номер запуска> -n TypeTune-test-<коммит>`.
2. Распакуйте архив. Внутри — `TypeTune-<коммит>.zip`, распакуйте и его тоже.
3. Завершите TypeTune: значок в строке меню → «Выйти из TypeTune». Другие переключатели
   раскладки (Caramba и подобные) тоже завершите: два сразу работать не должны.
4. Сохраните прежнюю версию: переименуйте `/Applications/TypeTune.app` в `TypeTune-old.app`.
   Перенесите новый `TypeTune.app` в `/Applications`.
5. В Терминале снимите карантин: `xattr -dr com.apple.quarantine /Applications/TypeTune.app`.
6. Разрешения. Каждая сборка подписывается заново, поэтому macOS считает её новым приложением.
   Откройте «Системные настройки → Конфиденциальность и безопасность» и в разделах
   «Универсальный доступ» и «Мониторинг ввода» удалите TypeTune кнопкой «−», затем снова
   добавьте его кнопкой «+».
7. Запустите TypeTune. Наведите курсор на флаг в строке меню: в подсказке должно быть «Работает».

Откат: завершить TypeTune, вернуть `TypeTune-old.app` на место и повторить шаг 6.

## 2. Шаги

Отвечайте по каждому шагу: «да» или «нет» и одна фраза, что вы увидели.

| # | Где | Что сделать | Что должно получиться |
| --- | --- | --- | --- |
| 1 | TextEdit, новый документ | Раскладка английская (ABC), набрать `ghbdtn ` | «привет », флаг 🇷🇺 |
| 2 | TextEdit | Раскладка русская, набрать `руддщ ` | «hello », флаг 🇺🇸 |
| 3 | TextEdit | Сразу после шага 1 нажать ⌘⌥Z | Вернулось `ghbdtn `. Повторный набор `ghbdtn ` больше не исправляется. После шага уберите слово: Настройки → «Сниппеты» → выбрать слово в «Исключениях после отмены» → «Снова исправлять» |
| 4 | Telegram (или другой мессенджер) | Набрать `ghbdtn ` в поле сообщения, не отправлять | «привет » |
| 5 | Telegram | Быстро, без пауз набрать `ghbdtn vbh ghbdtn vbh ` | Все слова исправлены, порядок букв не нарушен, не появился запрос ⌘⌥R |
| 6 | Telegram | Выделить мышью слово `ghbdtn`, дважды нажать Shift. Перед этим скопировать в буфер обмена любую картинку | Слово стало «привет». После шага ⌘V вставляет ту же картинку |
| 7 | Chrome, поле на странице | Набрать `ghbdtn ` | «привет » |
| 7а | Chrome, строка поиска Google (google.com или новая вкладка) | Набрать `ghbdtn `, затем отдельно набрать `ghbdtn` и дважды нажать Shift | Оба раза «привет», подсказки поиска не испортили текст |
| 8 | Веб-приложение, установленное из Chrome | Набрать `ghbdtn ` | «привет » |
| 9 | То же веб-приложение | Переключиться в него из другого окна и обратно несколько раз, каждый раз смотреть на флаг. Затем навести курсор на флаг | Флаг совпадает с раскладкой, которой реально идёт набор. В подсказке видна строка вида `com.apple.keylayout.…` — пришлите её, если флаг не совпал |
| 10 | Terminal | Набрать `ghbdtn ` в строке zsh, не нажимать Return | «привет » |
| 11 | Terminal | Набрать `sudo -v`, при запросе пароля ввести несколько букв, затем ⌃C | TypeTune ничего не меняет в поле пароля |
| 12 | Любое поле | Один раз нажать и отпустить Shift | Раскладка и флаг переключились |
| 13 | TextEdit | Добавить сниппет `yf` → `на` (Настройки → «Сниппеты» → «+», триггер «после пробела»), набрать `yf ` в английской раскладке | «на », флаг 🇷🇺. Если нет — проверьте, что включено «Автоматически исправлять раскладку RU/EN»: правила работают только с ним |

## 3. Если что-то не так

1. Сразу, пока ничего больше не набирали: Настройки TypeTune → «Сохранить отчёт…».
   В отчёте только коды этапов, вашего текста там нет.
2. Пришлите:
   - имя скачанной сборки (`TypeTune-test-<коммит>`);
   - номер шага и что вы увидели;
   - файл отчёта.
3. Дальше ничего не делайте с этой сборкой. Исправление придёт новой сборкой тем же путём.

## Что эта проверка не заменяет

Длинные автоматические прогоны (поток из тысяч слов, четыре часа) требуют NativeProbe на Mac
и в этой схеме не выполняются. Результат ручной проверки записывается как `user manual`
с коммитом сборки и не переносится на другие коммиты.


## 4. Ручная проверка нового интерфейса (ui-refresh, вариант А)

До начала запишите изменяемые значения, используйте собственный тестовый сниппет/слово
и после проверки верните прежние значения. Рабочие правила не удаляйте.
Для каждого пункта пришлите «да/нет» и наблюдение; это не автоматическая приёмка.

| # | Проверка | Ожидается |
| --- | --- | --- |
| UI1 | Открыть настройки, пройти все шесть разделов, изменить размер окна до минимума | Sidebar остаётся доступным, содержимое прокручивается; Tab и ⌘W работают |
| UI2 | Основное: пауза, RU/EN, все приложения, ранний режим, опечатки, ё, словарь; звук и выбор/сброс файла; автозапуск | Все значения доступны, возвращаются к исходным и сохраняются после перезапуска; предупреждение раннего режима видно |
| UI3 | Клавиши: ABC/Русская, Single Shift, Option, оба Shift, plain paste | Прежние настройки на месте; ручные команды/сочетания перечислены; вернуть исходную раскладку |
| UI4 | Исключения: добавить тестовое слово, ID приложения и правило auto; выбрать строку и удалить только тестовые записи | «+ / −», Return и выбор приложения работают; пустой список объяснён; все исходные записи сохранены |
| UI5 | Сниппеты: поиск, плюс, редактирование, enable, импорт/экспорт тестового файла, отмена/подтверждение удаления; «Снова исправлять» на тестовом learned word | Прежние данные/действия сохранены; удаление требует подтверждения, редактирование возможно с клавиатуры |
| UI6 | Редактор: триггеры, переменные, текст, регистр/другая раскладка, фильтры all/only/except, app picker/ID/remove; ошибки, preview, Esc/Return | Невалидное правило не сохраняется; отмена не меняет данные; длинный текст доступен через прокрутку |
| UI7 | Оформление: system/light/dark, все цвета, светлая надпись, выбрать/перетащить/убрать собственную тестовую картинку | Меняется компактный образец, сохранились прежние настройки; после проверки вернуть исходные |
| UI8 | Проверка: preview, все показатели/категории/исторический итог, refresh/retry/report | Показатели доступны через прокрутку, отчёт можно сохранить из любого раздела |
| UI9 | Меню строки меню: статус/раскладка, автоисправления, настройки, выход; открыть заново | Команды и флаг работают; не запускается второй экземпляр |
| UI10 | Светлая/тёмная темы, VoiceOver и клавиатурная навигация | Подписи понятны, контраст читаем, кнопки «+ / −» имеют имена |
| UI11 | TextEdit, новый документ: ABC → `ghbdtn `, русская → `руддщ ` | «привет » / «hello »; исходная раскладка восстановлена |

Баннеры нет доступа, Secure Input с владельцем, неподтверждённого результата,
сохранённых/ожидающих нажатий проверяются отдельно на соответствующем реальном состоянии.
Не провоцируйте их вводом пароля или повреждением пользовательских настроек.
Offline-снимки подтверждают только отрисовку подготовленных состояний.

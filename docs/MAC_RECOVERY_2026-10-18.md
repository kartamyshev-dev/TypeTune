## Результат

- Apple «Русская»: **8/8** по тексту, каретке и фактическому source ID.
- Удержание при задержке AX 150 мс и requested interval 10 мс воспроизведено:
  **10 событий сохранены**, качество длинного потока FAIL.
- ⌘⌥R при восстановленном точном префиксе: **FAIL, replay-suspended**.
  Контекст принят, но доставка не завершилась. Это не PASS положительного восстановления.
- Декодирование fixtures NativeProbe: **7/7**; guards документа, поля, PID, TCC и Secure Input сохранены.

## Причина удержания

`KeyboardService.mutate` после `.verified(after)` из `AccessibilityEditor.replace`
повторно читает поле с тем же общим deadline 200 мс. В исходном диагностическом
следе результат пришёл через 200,64 мс; в новом — через 196,24 мс, а commit уже
после общего deadline. При отсутствии второго снимка `finishMutation` сохраняет
очередь, поскольку не может подтвердить контекст. Это безопасный отказ в доставке,
а не доказательство потери нажатий.

Восьми коротким попыткам хватило времени на автоматическую доставку: перед ⌘⌥R
уже было «привет hello» (в одной — «привет he»). Они не проверяют положительное
восстановление удержанной очереди. В длинном фрагменте после удержания новый ввод
прошёл в документ и изменил его; первая ⌘⌥R корректно оставила очередь без доставки.
Интервал 10 мс — параметр паузы harness, а не измеренный интервал между всеми
событиями: каждый event дополнительно проходит проверку и паузу 12 мс.

## Положительный путь восстановления: найден сбой

В том же созданном тестом документе восстановлены «привет », caret `{7,0}` и ABC.
Только синтетический хвост документа заменён через UI; исходный текст сохранён
в evidence. Для настоящего HID-сочетания использован одноразовый pinned driver:
он заимствует неизменённый класс `Probe`, закрепляет точный путь и PID TextEdit,
требует точные текст/каретку/source и нейтральные модификаторы, затем вызывает
существующий `gesture("recover")`. Перед каждым event остаётся `verifiedField()`.

Диагностика показывает принятие контекста, переход к replay и затем
`replay-suspended` без `replay-forward`. Текст остаётся «привет ». Число pending
увеличилось 10 → 13 → 14: во время восстановления барьер удерживал также события
сочетания. Точный провалившийся guard identity/routing не различается текущей
диагностикой; объяснять его конкретным AX timeout пока нельзя.
Две дополнительные попытки pinned driver остановились до ввода на проверке
нейтральности модификаторов. Отдельная строго ограниченная попытка отпустить
собственный синтетический modifier-frame тоже остановилась до событий: ожидаемого
frame уже не было. Проверки не обходились. После тестов обе системные маски нейтральны.

## Apple «Русская»

Через системный UI временно оставлены ABC и Apple «Русская» вместо PC.
Кандидат запущен заново без диагностической задержки. Проверены:

1. ABC `ghbdtn` + Space → «привет », source Russian.
2. Russian physical `hello` + Space → «hello », source ABC.
3. Выделенное `\;br` → «ёжик».
4. Выделенное `|;br` → «Ёжик».
5. Выделенное ghbdtn + grave → «привет]».
6. Выделенное ghbdtn + tilde → «привет[».
7. Physical backslash при Russian → «ё».
8. Physical pipe при Russian → «Ё».

[Fixture](../corpus/native-apple-russian-v1.json),
[итоговый native-run](../research/evidence/mac-recovery-2026-10-18/apple-russian-final.json),
[проверка 8/8](../research/evidence/mac-recovery-2026-10-18/apple-validation.json).
Предварительные варианты с одиночными знаками и `\;` не преобразовались:
`Engine.manual` требует определимый язык. Это ограничение сценария, не ошибка
системной таблицы. Их raw evidence сохранено, к итоговому PASS они не относятся.
Первый запуск с ошибочным аргументом `--cases` остановился с `unknown_argument`.

## Изменения и состояние Mac

NativeProbe допускает явный source `Russian` и gesture `recover`; добавлена
проверка bounded allowlist. Добавлены Apple-fixture и данный отчёт.
Продуктовый код не изменён: повторное использование первого verified-снимка
и изменение механизма replay требуют отдельного обоснования свежести/адресата,
а не ослабления guards ради зелёного теста.

14 оставшихся синтетических событий удалены через штатный диалог; UI вернулся
в «Работает». После этого приложение остановлено, как до проверок. Все переключатели
остановлены. Настройки и статистика восстановлены с точным plist readback;
диагностический ключ удалён. Включены ABC и «Русская — ПК», текущая — PC,
меню ввода снова скрыто. [Readback](../research/evidence/mac-recovery-2026-10-18/restoration.json).

## Точка продолжения

Добавить технические boolean/reason diagnostics перед `suspendReplay` в ветке
identity/routing, без текста и данных документа. Повторить pinned recovery на новом
точном бинарнике; определить конкретный guard, исправить причину и только затем
закрыть положительное восстановление. Отдельно решить повторное AX-чтение после
verified при исчерпанном deadline. Не переносить этот native PASS Apple на новую сборку.
Четырёхчасовой прогон остаётся отложенным; полная приёмка PLAN не заявляется.

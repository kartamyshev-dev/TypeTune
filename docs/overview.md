# Обзор TypeTune

TypeTune — помощник ввода для Linux и macOS: общесистемная коррекция раскладки RU ↔ EN, сниппеты и (на Linux, opt-in) антидребезг отдельного устройства.

## Задача

Пользователь печатает слово не в той раскладке (`ghbdtn` вместо `привет`). TypeTune:

1. Замечает слово (жест **Double Shift** либо границу слова на **пробеле**).
2. Предлагает или выполняет перекладку по таблице клавиш US ↔ Русская (ПК).
3. Меняет источник ввода на язык исправленного слова, чтобы следующий текст шёл «правильно».

Дополнительно: сниппеты (`:date` + пробел), выученные слова, исключения слов и приложений, пауза, индикация раскладки.

## Платформы

| | Linux | macOS |
|---|---|---|
| Статус | Preview | Preview |
| Среда | Ubuntu 26.04, GNOME 50, Wayland | Apple Silicon, macOS 27 |
| Пакет | `.deb` | `.zip` → `TypeTune.app` |
| Ввод | opt-in evdev/uinput + session helper | CGEvent tap + Accessibility |
| UI | GTK / tray | Строка меню + окно настроек |

Windows не выпускается. Поведение в **каждом** приложении не гарантируется: редакторы, терминалы и кастомные поля обрабатываются по-разному.

## Приоритеты поведения

1. Ручное исправление (Double Shift) — предсказуемо и без «угадывания» словаря.
2. Автокоррекция на пробеле — только при достаточной уверенности (частотный скоринг, охрана URL/кода/коротких слов).
3. Сниппеты — явный триггер.
4. Антидребезг — отдельный opt-in, не мешает текстовой коррекции.

## Границы продукта

- Не «восстановление текста» в произвольном документе: правится **последнее слово** у каретки.
- Не облачная синхронизация и не телеметрия текста.
- Не универсальный IME и не замена системной раскладки «на лету» в каждой программе без подтверждённого пути инъекции.
- Захват/инъекция клавиш требует системных разрешений; без них приложение честно показывает «недоступно», а не «работает».

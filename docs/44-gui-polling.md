# 44 — Мигание GUI при опросе состояния

2026-09-16. Base `18f366ed58ddb08799e527f0d4599a0bcf513f29` + этапы 40–44.

Причина: каждый status poll (3 секунды) устанавливал busy и отключал кнопки,
затем включал их при завершении. Это создавало видимое мигание sensitivity.

Изменение: отделены занятость worker и блокировка управляющей операции;
фоновое чтение не отключает кнопки. Render пропускается, если отображаемые
данные, ошибка и состояние управляющей операции не изменились. Programmatic
switch updates защищены отдельным rendering guard. Одна команда пользователя
во время read сохраняется и выполняется после него, без параллельных mutations.

GUI-44: controlled GTK fixture с Event задерживает read. До исправления падает
на disabled кнопке. После — нет notify::sensitive при неизменном poll, клик pause
во время read не потерян, прежние pause/resume/auto/stop/start/error cases проходят.
28 IBus/controller unit tests PASS. Ubuntu 26.04.1, GTK4, GNOME Wayland.
Rust и text runtime не менялись; их тесты повторно не запускались.

Установленный gui.py обновлён, перезапущено только окно. Keyboard runtime и
настройки коррекции сохранены. Пользовательская оценка мигания после правки
ещё не получена. [Evidence](evidence/44-gui-polling.txt).

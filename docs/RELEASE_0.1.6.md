# TypeTune 0.1.6 (12)

Предварительный релиз для macOS 14+ на Apple Silicon. Подпись ad-hoc, без нотаризации: при первом
запуске откройте приложение через контекстное меню «Открыть» или снимите карантин
(`xattr -dr com.apple.quarantine /Applications/TypeTune.app`). После обновления заново выдайте
TypeTune разрешения «Универсальный доступ» и «Мониторинг ввода».

## Новое

- **Сниппеты.** Сокращение заменяется текстом во всех приложениях: `;адр` — сразу, `спс` — после
  пробела. Работают и в другой раскладке (`;flh` = `;адр`), переносят регистр (`Спс` → «Спасибо»).
  Переменные `{{дата}}`, `{{время}}` с форматом, `{{буфер}}`, `{{курсор}}`. ⌘⌥Z сразу после вставки
  возвращает сокращение. Длинный и многострочный текст вставляется через буфер обмена, прежнее
  содержимое буфера возвращается. Вкладка «Сниппеты» заменила «Правила»; прежние правила
  переносятся автоматически. Импорт и экспорт в JSON.
- **Chrome.** Многострочная вставка ждёт, пока поле покажет стёртое сокращение; ⌘V отправляется
  полной последовательностью нажатий. Telegram: многострочные сниппеты сверяются корректно.

## Как проверено

- CI на теге: Linux и macOS, selftest, корпуса, пробник контроллера с проверками хранения
  сниппетов на настоящем Store; архив собран `scripts/package.sh` из чистого тега, приложение
  из архива запускается без каталога сборки.
- Агент на Mac (ограниченная матрица, сборка `92a0ba8`): Chrome 16, Safari 11, Заметки 11,
  Telegram 11, TextEdit 26 — 75/75 выбранных случаев. После неё ожидание стирания в Chrome
  увеличено с 80 до 600 мс — эта правка native не проверялась.

## Ограничения

- Не проверены: Slack, VS Code, Word, Terminal, ввод пароля целиком, четырёхчасовой прогон.
- Chrome: однажды многострочная вставка оставила поле пустым; найдена соответствующая ошибка
  Chromium 568453825, после перезапуска Chrome не повторилось. Постоянное решение не доказано.
- Сокращение «сразу» не срабатывает на нажатиях, задержанных во время предыдущей правки;
  сниппеты не учитываются в статистике; раскладка после сниппета не меняется.
- Строка поиска Google: первое слово после клика исправляется Double Shift, если поле не читается.

## ⌘⌥R — PASS с непустой очередью

Новый синтетический документ TextEdit, AX-задержка 150 мс, раннее исправление OFF.
NativeProbe адаптирован к введённой в приложении паузе: только для уже ограниченного
точного сценария `interruptRecover` после `ghbdtn ` выдерживается 170 мс, затем
вводится `he` и временно меняется ABC → RussianWin → ABC. Валидация fixture и
проверки документа, поля, PID, разрешений, Secure Input не изменены; 8/8 pure fixture
tests пройдены. Это синхронизация теста, а не обход защиты или изменение приложения.

До сочетания подтверждены `ghbdtn `, каретка {7,0}, ABC; в трассе pending=4.
После ⌘⌥R — точные `ghbdtn he`, каретка {9,0}, ABC. Семь подтверждений доставки
включают удержанные события и отпускания сочетания; последний forward сообщает
queueEmpty=true, затем replay-drained. Не было повторов или потери хвоста.
[Native](../research/evidence/mac-hosts-2026-10-18/recovery.json),
[trace](../research/evidence/mac-hosts-2026-10-18/recovery-trace.json).
Затем диагностический ключ удалён и приложение перезапущено без задержки.

## Apple «Русская» — непостоянные пропуски ручного действия

Через системный UI временно включена пара ABC + Apple Russian, ПК-вариант удалён
на время теста, затем восстановлен. Две серии в новых TextEdit-документах:
**7/8** и **6/8**, совокупно **13/16** по точным тексту, каретке и source ID.
Автоматическое RU↔EN — 4/4; физические ё/Ё — 4/4; ручное преобразование выделения — 5/8.

В первой серии не сработал `apple-manual-grave`; в повторе — `apple-manual-Yo`
и `apple-manual-tilde`. Во всех трёх случаях исходный текст и выделение сохранились,
раскладка осталась ABC. Это FAIL действия, не PASS безопасности вместо качества.
Трасса содержит три `explicit-enqueue` с anchor=false, пять с anchor=true и
успешной полной explicit-context проверкой, а также пять snapshot deadlineExceeded.
UI сообщил «Контекст ещё не подтверждён». Прямой причинный порядок каждого AX
тайм-аута требует дальнейшего разбора; ошибку таблицы символов этим не установили.

[Первая серия](../research/evidence/mac-hosts-2026-10-18/apple-russian.json),
[повтор](../research/evidence/mac-hosts-2026-10-18/apple-russian-repeat.json),
[trace](../research/evidence/mac-hosts-2026-10-18/apple-trace.json).
Существующая `corpus/native-apple-russian-v1.json` уже фиксирует эти ожидания;
ожидания и защитные бюджеты не подгонялись под результат.

## Chrome — семь коротких случаев PASS, поток FAIL

Отдельная новая вкладка собственного локального fixture
`http://127.0.0.1:18763/?fixture=LP-CODEX-001`. Исходные вкладки не изменялись.
Helper перед событиями проверяет точный URL, label поля, PID, окно/поле,
разрешения, Secure Input и посторонние модификаторы. Clipboard не используется
для испытательных нажатий, Enter не отправляется. Early остаётся OFF.

| Поле | Авто `ghbdtn` | Правильное `hello` | Double Shift выделения |

| single | PASS | PASS | PASS |
| textarea | PASS | не запускалось | PASS |

helper отдельно не проверялась. Каждый отчёт связан с GUI/helper SHA и неизменностью
бинарника; файлы `chrome-single-*.json`, `chrome-plain-*.json`, `chrome-rich-*.json`
в [evidence](../research/evidence/mac-hosts-2026-10-18/validation.json).

Дополнительный contenteditable-поток из 20 слов не прошёл: осталось `ghbdtn ` × 20

пробел уже совпал, но завершённых токенов в новом прогнозе не было. Причина

## Терминалы — native заблокирован инструментом

Computer Use отказал в доступе отдельно к `com.apple.Terminal` и
`com.mitchellh.ghostty`: “Computer Use is not allowed to use the app … for safety reasons.”
Окна не открывались, native-события TerminalProbe не отправлялись. Блокировка не
обходилась запуском окна через другой механизм. [Отказ](../research/evidence/mac-hosts-2026-10-18/terminal-native-blocked.json).

Доступные отдельные проверки: **6/6** на реальном zsh/vared в отдельном PTY с
mock-сервером и **36/36** production dispatch helper с mock-политикой без socket IO,
реальных полей и event tap. Они не являются native-приёмкой Terminal/Ghostty.
[PTY](../research/evidence/mac-hosts-2026-10-18/terminal-zle-tests.txt),
[dispatch](../research/evidence/mac-hosts-2026-10-18/terminal-dispatch.json).

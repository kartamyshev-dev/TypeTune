# 39 — Повторный Double Shift меняет слово и раскладку обратно

2026-09-16. HEAD `ca6ccaec05c511ff1e1fa210a5e703c5f5269365` + рабочие изменения.
Область изменения — активный opt-in compatibility runtime.

## Результат

После завершения отправки замены последнее исправленное слово остаётся в
ограниченной предполагаемой истории. Следующий Double Shift снова преобразует
его и меняет раскладку. Например: `ghbdtn → привет → ghbdtn → привет`.
То же действует после автоматической коррекции, включая завершающий пробел.
Каждый жест — новая явно запрошенная операция, не автоматический retry.

На старом коде regression test воспроизвёл потерю слова: обработчик результата
безусловно очищал историю. Теперь runtime сохраняет replacement только для
matching transaction с результатом `injected-unverified`. При rejected,
indeterminate, отмене или запоздалом ответе история не восстанавливается.
Навигация, щелчок, смена focus/layout и остальные invalidation guards остаются.
При вводе следующего слова исправляется уже оно; предыдущая замена не воскресает.
Во время исполнения status показывает pending, а не старый результат.

## Проверки

Ubuntu 26.04.1 / kernel 7.0.0-31-generic, GNOME/Mutter 50.1, GTK 4.22.4.
12 Python compatibility tests PASS, включая три новых regression cases:
повторный жест, отказ/отмена/поздний ответ, навигация/следующее слово.

[Native Wayland](evidence/39-repeat-wayland.txt) и
[XWayland](evidence/39-repeat-xwayland.txt):

- COMPAT-RETOGGLE: исходное слово меняется RU → US → RU без нового набора;
  каждый результат независимо читается из поля, источник проверяется.
- COMPAT-RETOGGLE-AUTO: повторная замена после auto сохраняет пробел.
- COMPAT-01 и GNOME/SWITCH регрессии: text/caret, следующая RU буква, pause и quit.

Stand использует контролируемый Feed и compositor virtual keyboard, как на этапе 37.
Реальные поля в режиме совместимости не дают readback: результат по-прежнему
`injected-unverified`, а не подтверждённый committed text. Повторять жест следует
после завершения предыдущей замены; ввод во время исполнения отменяет операцию.

## Установка

Изменяется только Python runtime; GNOME extension и Rust helper прежние.
Обновление запущенного режима выполняется остановкой, копированием runtime и
повторным compat-on; logout/login не требуется.

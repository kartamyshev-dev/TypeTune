# Spotlight: правка не срабатывала

2026-10-26. Пользователь: «на macOS не работает автоисправление и исправление по
двойному Shift в приложении Spotlight». Проверка на установленной 0.1.8 (14),
PID 12986. Симптом подтверждён, причина найдена, исправление собрано, native-проверка
на этом Mac — **NOT_RUN** (см. «Состояние проверки»).

## Симптом

Оба сценария в Spotlight (⌘Space) не меняли текст:

| Сценарий | Ввод | Ожидание | Наблюдение |
| --- | --- | --- | --- |
| автоисправление после пробела | `ghbdtn ` в ABC | `привет ` | осталось `ghbdtn` |
| Double Shift по слову | `ghbdtn`, два Shift | `привет` | осталось `ghbdtn` |

Контрольный шаг: после попытки правки в Spotlight **в поле ввода чата появился
посторонний текст** — то есть синтетические нажатия ушли не в Spotlight, а в
приложение, которое оставалось frontmost.

## Причина

Универсальный режим брал цель из `NSWorkspace.shared.frontmostApplication` и отправлял
нажатия `CGEvent.postToPid(pid)` этому процессу.

Панель Spotlight — **неактивирующая**: `frontmostApplication` продолжает указывать на
прежнее приложение, а клавиатуру получает поле поиска, принадлежащее другому процессу.
Замер AX (`research/evidence/spotlight-2026-10-26/ax-scope.txt`) при открытом Spotlight:

```
front=dev.warp.Warp-Stable/23317
systemFocus=[pid=690 app=com.apple.campo/Siri role=AXTextField sub=AXSearchField
             value=len0 settable=true range=0+0]
appFocus=[pid=23317 app=dev.warp.Warp-Stable/Warp role=AXTextArea value=len81]
```

То есть системный фокус — поле поиска в процессе 690 (`com.apple.campo`, на этом
macOS 27 Spotlight обслуживается им), а `frontmostApplication` — 23317. Нажатия,
отправленные в 23317, в поле поиска не попадают; в чате они видны потому, что это
приложение действительно было frontmost.

Отчёт диагностики TypeTune подтверждает, что приложение считало цель найденной и
правило «вслепую» (`research/evidence/spotlight-2026-10-26/report-tail.json`):

```
universal-boundary  decision=true, target=true
unreadable-field    focusedField=false          ← поле чужого (frontmost) приложения
universal-result    confirmed=true, readable=false
```

## Исправление

Перед правкой универсальный режим уточняет цель по системному элементу с фокусом
(`AXUIElementCreateSystemWide` → `AXFocusedUIElement`) и переадресует клавиши, если:

- элемент — текстовый ввод (`AXTextField`, `AXTextArea`, `AXComboBox`, `AXSearchField`);
- он принадлежит **запущенному приложению** (не хелперу/рендереру: `NSRunningApplication`);
- это не пароль (`AXSecureTextField`);
- приложение не исключено настройками.

Такая цель помечается `focusTarget`; проверки «цель всё ещё в фокусе», чтение
выделения и подтверждение результата идут по процессу элемента, а не по
`frontmostApplication`. Обычные приложения не меняются: там оба процесса совпадают.
Код: `KeystrokeDestination` (Core), `AccessibilityEditor.focusedElement()`,
`KeyboardService.runKeystrokes/performKeystrokes/finishKeystrokes/finishMutation`.

### Второй дефект: потерянная Backspace

После переадресации правка в Spotlight пошла, но оставила первую букву: `ghbdtn `
→ `gпривет`. Поле съело одну Backspace из пачки; подтверждение по суффиксу это
пропускало (`«gпривет »` оканчивается на `«привет »`).

Правка стала двухфазной для читаемого поля (`56bda63`): сначала Backspace-ы, затем
сверка «текст до каретки равен тексту левее токена», недостающие Backspace-ы
добираются (не больше двух повторов и только по ещё не удалённому префиксу токена),
и только потом печатается замена. Если удаление не подтвердилось, набранный хвост
возвращается обратно — полуслова не остаётся; если поле разошлось иначе, статус
«проверьте текст». Итог сверяется точным равенством, а не суффиксом.

Ограничения, известные сейчас:

- сниппеты по-прежнему выбирают цель по `frontmostApplication` (вне этого исправления);
- если AX не отдаёт системный фокус, остаётся прежнее поведение (слепая правка в
  frontmost-приложение);
- раскладка по-прежнему переключается глобально, как и раньше.

## Состояние проверки

| Утверждение | Статус |
| --- | --- |
| Причина (frontmost ≠ процесс с фокусом) | подтверждена замером AX и посторонним текстом в чате |
| Переадресация в Spotlight (`5c0b99e`) | native: `focus-target retargeted=true`, поле прочитано, текст исправлен |
| Потерянная Backspace | воспроизведена пользователем (`gпривет`); двухфазная правка в `56bda63`; native `f6deb2b`: текст исправлен точно |
| Восстановление после удержанного ввода | native `f6deb2b`: «Ожидает восстановления»; `735b114` исправляет маршрут повтора |
| Native дважды на `735b114` | **NOT_RUN** — пользователь остановил итерации |
| Отсутствие регрессии в TextEdit/Chrome | **NOT_RUN** |
| Влито в `main` / выпущено | **нет** |

# Ghostty и Terminal — локальный zsh

Причина исходного отказа: обычный AX backend намеренно исключает терминалы.
Их AXTextArea может содержать экран и scrollback, а не редактируемую команду.
Расширять этот backend до терминалов небезопасно.

Подготовлена отдельная интеграция ZLE: `layoutpilot.zsh` меняет только LBUFFER
и RBUFFER текущего локального редактора. Пробел запрашивает автоисправление;
Double Shift и ⌘⌥Space — ручное исправление, ⌘⌥Z — отмену последней неизменённой
замены. Используются прежние настройки, исключения и классификатор.
Обычная AX-замена в терминалах по-прежнему запрещена.

Связь — локальный Unix socket с правами0600 и проверкой UID. Перед решением
проверяются активный host, Secure Input, AXTextArea, окно с уникальной меткой
`[LP:UUID]` и закреплённое поле. При завершении ZLE соединение закрывается.
Нет чтения scrollback, истории, clipboard или отправки Backspace/Enter.
При недоступности приложения и тайм-ауте исходный ввод сохраняется.

Граница поддержки: локальный интерактивный zsh в Ghostty/Terminal, новые окна
после подключения скрипта. SSH, vim, другие shell и произвольные программы
в PTY не поддерживаются. При открытом редакторе строк заголовок содержит
короткое имя каталога и `[LP:UUID]`; метка нужна для проверки окна.

## Проверка и продолжение

`python3 scripts/test_terminal_zle.py -v`: 6/6 на настоящем zsh/vared в отдельном
PTY с mock-сервером. Проверены auto/manual/undo, правильное слово, тайм-аут,
отказ при управляющих символах. Это не native-проверка терминальных окон.
CLI selftest:626/626 offline-инвариантов, включая сохранение запрета AX backend
и отдельный allowlist двух терминалов. XCTest не запускался.

Подготовлены `Tools/TerminalFixture.zsh` и отдельный `Tools/TerminalProbe.swift`.
Fixture никогда не выполняет введённое; помощник перед каждым событием проверяет
PID, nonce, поле, окно, разрешения, Secure Input и чужие модификаторы. Payload
ограничен ghbdtn/hello, пробелом и сбалансированным Shift; Enter/clipboard нет.
Native запуск ожидает согласования согласно OTHER_HOSTS_PREPARATION.md.
Версия0.1.1 установлена 2026-10-17 в /Applications/LayoutPilot.app.
Блок source добавлен в пользовательский .zshrc; откройте новую вкладку.
Для удаления интеграции удалите блок между BEGIN/END LayoutPilot из .zshrc.
Native не выполнен; приложение ожидает обновления прежнего AX-разрешения через Touch ID.

# 36 — Double Shift, автокоррекция и межприложенческий профиль

Дата: 2026-09-16. HEAD `ca6ccaec05c511ff1e1fa210a5e703c5f5269365` + рабочие изменения.
Актуальная [инструкция пользователя](35-user-test.md).

## Результат

- Два коротких полных нажатия одного Shift исправляют последнее слово US↔RU.
  Только после подтверждённого результата замены выбирается TypeTune RU/US для
  дальнейшего ввода. Левый и правый Shift поддержаны; смешанная пара не считается жестом.
- Автокоррекция включена по умолчанию. Триггер — подтверждённый приложением
  одиночный пробел после обычного набора; исправляется известное словарю слово.
  Смена языка выполняется после подтверждения замены. Неизвестные слова остаются.
- Убрано ограничение списка приложений одним Chrome. Для остальных native Wayland
  приложений дополнительно нужны свежие AT-SPI доказательства: PID окна, focused
  editable Text, отсутствие выделения, совпадение текста и каретки с IBus.
  Этот маршрут принят в GNOME Text Editor; остальные приложения требуют acceptance.
- Controller обслуживает два IBus-источника; `auto-on`/`auto-off` подтверждают
  effective state. Значение действует до завершения runtime, при новом запуске — on.
- F8/F9 сохранены как диагностические команды старого профиля, без смены языка.

## Контракты

Обычные Down/Up сразу проходят приложению. Жест не поглощает Shift. Интервал между
первым отпусканием и вторым нажатием ≤350 мс, удержание ≤200 мс. Repeat, другая
клавиша, смена контекста и pointer click отменяют жест. IBus не предоставляет
исходное время события: используется monotonic время поступления callback.

Prepare/authorize/observe проходят общий Rust executor. Auto matcher не редактирует
самостоятельно. План ограничен TTL 500 мс; обычный ввод во время плана отменяет его.
Признак простого committed ввода устанавливается только при точном echo символа
с ожидаемой кареткой в пределах 250 мс. Автокоррекция ждёт такой же echo пробела.
Clipboard и evdev grab не используются. Текст не пишется в runtime-логи.

Shell owner/instance/generation/window/source проверяются асинхронно перед prepare
и edit. AT-SPI выполняется отдельным единственным worker, вне IBus key callback.
Неизвестный контекст запрещает замену. `SetTypeTuneMode` проверяет свежие guards и
выбирает только собственные US/RU-источники; клиент отдельно проверяет результат.
`mode_result: unconfirmed` не запускает повторное переключение/редактирование.

IBus delete+commit не атомарны. Доступные guards уменьшают гонки, но не дают общей
гарантии для composition, быстрых JS edits и произвольных пользовательских редакторов.
После неопределённого edit нет слепого retry. Немедленный повторный Double Shift
для undo не гарантируется: смена источника инвалидирует прежний контекст.

## Словарь

Встроенный пилотный список: 150 русских и 149 английских слов. Создан в этой
итерации из общеупотребительных слов, без импорта сторонней базы или baseline
`dict/`. Распространяется на условиях MIT проекта; это не частотный словарь и не
оценённый на репрезентативном корпусе детектор. Источник и SHA-256 зафиксированы в
[data/README.md](../crates/typetune-engine/data/README.md).

Автоматически допускаются слова длиной 4–32 символа в lower/title/UPPER регистре,
если исходного слова нет в обоих списках, а преобразованное есть в целевом.
Кодоподобные, смешанные, короткие и неизвестные слова не исправляются.
Положительные fixtures и 18 отрицательных примеров — регрессии, не оценка precision.

## Ограничения и продолжение

Это ещё не поддержка всех приложений. XWayland, терминалы, пароли, игры, canvas
редакторы и поля без IBus surrounding text/AT-SPI proof не приняты. Chromium-профиль
остаётся ограниченным plain-text маршрутом. Другие браузеры и desktop-приложения
нужно проверять отдельно по содержимому, каретке, selection и composition.

Следующая работа: пользовательский feedback и матрица реальных приложений;
расширение и оценка словаря на размеченном корпусе; UI настроек/исключений;
условный undo; отдельные backend-ы для неподдержанных сред. Полнота G2 не заявляется.
Основная сессия требует повторного входа для расширения v3 и двух IBus engines.

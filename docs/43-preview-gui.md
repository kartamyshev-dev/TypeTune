# 43 — Графическое управление Linux preview

2026-09-16. Base commit `18f366ed58ddb08799e527f0d4599a0bcf513f29` + этапы 40–43.
Пользователь попросил сначала GUI, чтобы дальнейшие слова/исключения не требовали CLI.

## Реализовано

GTK4 окно на русском: статус, язык, пауза/продолжение, автокоррекция, остановка,
запуск compatibility либо IBus, обновление состояния, ошибки и ограничения.
Ярлык TypeTune устанавливается в пользовательское меню приложений и удаляется
при uninstall. Один экземпляр окна на session bus; закрытие не выключает runtime.
Открытие окна само не включает коррекцию. Настройки сейчас действуют до перезапуска
режима; автозапуск и постоянные настройки не заявляются.

Новый entry point: `integrations/ibus/gui.py`, CLI `./scripts/typetune-test gui`.
Старый Rust `typetune-gui` относится к legacy Daemon API и не запускается этим ярлыком.
GUI использует текущий controller, а не параллельную реализацию управления:
worker вызывает controller с ограниченным набором argv без shell; после команды
читает фактический status. GTK thread и обработка ввода не блокируются.

Одна операция за раз; status обновляется каждые 3 секунды. Switch не подтверждает
настройку до readback. Timeout/error показывается, неизвестное состояние не
превращается в enabled/available. Остановка остаётся доступна после ошибки чтения.
Установка и перезапуск GNOME выполняются существующим installer, не кнопкой GUI.

изменения, неподтверждённый успех, failure/timeout, некорректный status/команда.
GUI-43-GTK: `python3 integrations/gui/smoke.py` — реальное GTK окно с контролируемым
requester: pause/resume, auto-off, stop/start, missing bridge, failure/recovery.
Снимок собственного fixture окна визуально проверен; текст и кнопки помещаются.

GUI-43-LIVE: установленное окно → controller → compatibility D-Bus:
пауза/продолжение, auto-off/on подтверждены readback; прежнее состояние восстановлено.
GUI-43-DESKTOP: установленный desktop entry разобран Gio и успешно открыл окно.
28 IBus/controller Python tests + 13 compatibility tests PASS. Rust не менялся
в этом этапе; предыдущая проверка 118 PASS, без повторного запуска.

Среда: Ubuntu 26.04.1, GNOME Wayland, GTK 4.22, системный Python/GI.
[Evidence](evidence/43-gui.txt). Проверка UI управления не заменяет acceptance
исправления текста в других приложениях. Live IBus управление новым окном отдельно
не проверено. Пароль/selection ограничения compatibility сохраняются.

## Универсальная замена — ветка `universal-input`

По решению пользователя TypeTune работает во всех приложениях одним способом: свой буфер
набранного слова, Backspace и повторный набор, со сверкой через AX там, где поле читается.
Этапы U0–U7 сделаны: ядро проверено на Linux, приложение собирается в CI на macOS, проверки
`RuntimeRecoveryProbe` пройдены. **Native-проверки (U8) не проводились** — чек-лист в
[UNIVERSAL_INPUT_PLAN](UNIVERSAL_INPUT_PLAN.md#чек-лист-u8-для-mac-всё-not_run). До них ветку
не сливать в `main`. Native-PASS прежнего механизма к новому не переносятся.
Пошаговая инструкция для агента на Mac — [MAC_AGENT_HANDOFF](MAC_AGENT_HANDOFF.md).

## Точка продолжения

1. Выполнить на Mac чек-лист ниже. Сборка и пробник уже прошли в CI; главное — native-проверки.
2. После native-проверки закрыть этапы 4, 5 и 7 в PLAN и записать результаты в журнал.
3. Сниппеты — [SNIPPETS_PLAN](SNIPPETS_PLAN.md), ветка `snippets`: решения S0 приняты
   (DECISIONS п. 28), S1–S3 готовы (Linux offline). Ядро (S4) делается до U8, GUI — только после него.

## Чек-лист на Mac (всё NOT_RUN)

1. `scripts/build.sh` (release, подпись, bundle) и selftest release CLI. Debug-сборка, `ci_core.sh`
   и `runtime_recovery_probe.sh` уже прошли в CI на macOS; повторить локально по желанию.
2. Установка по правилам AGENTS.md: обновить запись TypeTune в разрешениях через системный UI.
3. NativeProbe в новом тестовом документе TextEdit по правилам AGENTS.md:
   - `ghbdtn/` и `руддщю` с пробелом;
   - `IDs`;
   - пауза с опечаткой «превет»;
   - прокрутка во время набора;
   - выделение перетаскиванием и Double Shift;
   - быстрый набор во время replay;
   - восстановление ⌘⌥R и окно сброса нажатий;
   - ⌘⌥Z учит слово `ghbdtn`, а не `ghbdtn/`.
4. Таблица раскладки: для ABC + «Русская – ПК» она совпадает с авторской; для Apple «Русская»
   «ё» и знаки идут по реальным клавишам.
5. Время первой проверки слова после запуска: словарь прогревается в фоне.
6. В конце восстановить исходные раскладку, настройки и состояние оригинала.

## Открытые условия и известные ограничения

- Полная приёмка PLAN не заявляется. Длительный четырёхчасовой прогон пользователь отложил.
  Открыты пункты PLAN по Chrome: раннее исправление и повтор IP/порта в omnibox.
- Латинские трёхбуквенные аббревиатуры и имена иногда конвертируются (`NBC` → «ТИС», `Tim` → «Ешь»).
  Поведение оставлено решением пользователя (DECISIONS п. 25); отмена ⌘⌥Z запоминает исключение.
- Слова в CamelCase с двумя заглавными в начале теряют регистр второй буквы (`EBook` → `Ebook`).
- Замена текста поддерживается в TextEdit, Chrome и Codex, а в Terminal и Ghostty — через интеграцию zsh.
- Если новая русская раскладка включена без смены текущей, таблица обновится только после
  ближайшей смены раскладки.

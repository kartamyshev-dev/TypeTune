# LayoutPilot

- Общение и пользовательский интерфейс — по-русски.
- Начинай с docs/STATUS.md, docs/PLAN.md и docs/FEATURES.md. Обновляй точку
  продолжения, не переноси PASS между версиями кода и разными видами проверки.
  STATUS — только текущее состояние; записи о проверках добавляй в docs/JOURNAL.md.
- Отмечай чекбокс только после проверки и ссылки на evidence. Гипотеза,
  псевдокод, offline, native и сравнительная приёмка — разные утверждения.
- Сохраняй исходные данные пользователя. Оригинал установлен в /Applications;
  анализируется зафиксированная копия в research/private, исключённой из Git.
- Не добавляй бинарники, декомпиляцию и извлечённые словари оригинала в поставку.
- Словарь/код прототипа самостоятельные. Новые расхождения становятся fixtures;
  контрольную выборку не использовать для настройки под результат.
- REA: scripts/rea.sh; не открывай повторные Ghidra imports без проверки snapshot.
- Быстрая проверка: swift build --product layoutpilot-cli;
  .build/debug/layoutpilot-cli selftest; python3 scripts/evaluate_corpus.py.
- XCTest пока отсутствует в CLT. CLI selftest — отдельно исполненные инварианты,
  не утверждение о прохождении XCTest.
- Сборка: scripts/build.sh. Поставка из чистого коммита: scripts/package.sh.
- Агент на Mac работает по docs/MAC_AGENT_GUIDE.md (решение пользователя 2026-10-18,
  DECISIONS п. 31; прежний п. 29 отменён). Ввод в приложения кроме TextEdit — только
  после явного разрешения пользователя в этой сессии, с записью в журнал.
  CI на macOS выкладывает артефакт `TypeTune-test-<коммит>`; ручная проверка
  пользователем — docs/MAC_MANUAL_CHECK.md (вид проверки `user manual`).
- NativeProbe разрешён пользователем только для новых локальных тестовых
  документов TextEdit. Перед каждым событием проверяются документ, поле, PID,
  разрешения и Secure Input; не ослаблять эти проверки ради результата.
- Никогда не запускай два переключателя одновременно. В конце восстанови
  исходное состояние оригинала, раскладку и временно изменённые настройки.
- Ad-hoc пересборка может аннулировать AX-доступ: после окончательной сборки
  обнови только запись LayoutPilot через системный UI и перезапусти приложение.
- Полная готовность не заявляется без выполнения всех приёмочных условий PLAN.

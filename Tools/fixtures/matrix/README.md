# Синтетические случаи матрицы

`scenarios.json` содержит только самостоятельно составленный текст. Для запуска
добавьте к выбранному случаю `bundle`, точное наблюдённое `window` и `description`
нового пустого тестового поля. Если AXDescription отсутствует, задайте JSON null;
объекты поля и окна всё равно закрепляются и проверяются перед каждым событием.
Не используйте существующий текст пользователя. Return не отправляется.

S5 выделяет слово двойным щелчком мыши, сохраняет все исходные форматы clipboard
в памяти, кладёт тестовую картинку, выполняет Double Shift и проверяет неизменность
её представлений, затем восстанавливает исходный clipboard с readback. Буквальная
вставка картинки через ⌘V — отдельная, пока не выполненная проверка.

S6 требует точного исправленного текста и раскладки перед ⌘⌥Z; без этого отмена
не отправляется. Случай обучает исключение vbh. Удалите только его кнопкой «Снова
исправлять» и подтвердите семантическое равенство исходных настроек.

S8 строит собственное слово abcdef и печатает в середине. Очистка начинается
только после точного совпадения текста/каретки/раскладки/флага; сохранность обоих
фрагментов проверяется до удаления собственного fixture.

S10 только активирует приложение, читает пустое поле и сопоставляет настоящий
флаг/подсказку TypeTune с текущим TIS source. Клавиатурных событий и выбора раскладки
нет. Для сценария выполните три круга переходов между приложениями.

S13 требует отдельно подтвердить включённую автозамену macOS. Допустимый безопасный
пропуск (`123 превет ` вместо `123 привет `) анализируется отдельно как LIMIT, а
не объявляется точным PASS. S1/S7 при нечитаемом первом слове — также отдельный LIMIT.

Эти случаи не закрывают всю MAC_AGENT_GUIDE; границы каждого результата — в evidence.
